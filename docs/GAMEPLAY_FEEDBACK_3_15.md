# 3.15 플레이 피드백 반영

2026-10-12. 성장 완성 시점을 늦추고 위험을 감수한 탐사에 보상을 집중한다. 기존 조작·무기/기체 조합·저장 형식·난이도 해금·온라인 서비스 범위는 유지한다.

| 피드백 | 적용 규칙 |
| --- | --- |
| 1. 중반부터 쉬움 | 150초 이후 모든 살아 있는 적/새 적의 체력에 추가 압박 S를 적용. S=1+1.8×clamp((t−150)/450,0,1)^1.4+min(0.45,장착 파츠 수×0.025). 피해는 S^0.25, 속도는 S^0.12. 기존 후반 증원/시간/난이도 배율과 함께 적용한다. 남은 체력 비율을 보존하고 프레임마다 중첩하지 않는다. |
| 2. 파츠 희소성 | C/B 미션은 파츠 없음, A급만 1개. 정예/보스는 기존 보급만 유지하고 확정 파츠 제거. 탐사 파츠는 첫90초, 이후105초 간격, 2층 깊이1.8에 생성. 동시에 탐사품1개, 실제2층 진입·접촉 회수. 수명45초, 파츠 종류/6개 한도/조합은 유지한다. |
| 3. 행성 방어 | 기체 중심 거리≤방어 반지름+기체 반지름(13px)이면 유지. 선체가 원에 닿는 순간도 포함. 완전히 이탈하면 초기화한다. |
| 4. 소수점 횟수 | 처치·회피·왕복·돌진·코어 횟수는 정수. 시간 목표인 외곽 정찰만 소수 첫째 자리 초를 유지한다. |
| 5. 후반 경험치 | 다음 레벨 요구=9+4×(레벨−1)+0.7×max(0,레벨−10)^2. 레벨10까지 기존과 같고, 20은155(기존85), 30은405(기존125). 미션 추가 강화는 레벨/경험치와 별도다. |
| 6. 위험 보상 | 기체가 안전/1층/2층/3층에 있으면 경험치와 처치 점수 ×1/1.25/1.6/2.1. 처치 점수는 처치 순간, 경험치는 획득 순간의 기체 위치를 사용. 정예/보스 처치 추가 보너스도 적용. 점수는 정수 반올림, 경험치는 소수 누적. 필드 경험치에는 배율을 미리 저장하지 않아 이중 적용하지 않는다. 300개 경험치 상한으로 즉시 지급하는 경우는 지급 시 위치를 따른다. |
| 7. 위험/이득 설명 | 좌상단에 안전 시 전체 배율·손상/감속 경고, 외곽에서 현재 층/배율/추가HP손상/추진비율/복귀 안내. 배율 보상에 금색 점수·청록 경험치 숫자 표시. 표시 수량은 배율을 적용한 최종 지급량이다. 효과 줄이기에서도 숫자/배율을 유지하며 밀집 보상은 같은 유형·같은 배율로 합산한다. |
| 8. 전장 위험 | t/600을0~1로 제한. 번개 폭 최대+45%, 동시 통로는0~239초1개/240~479초2개/480초부터3개. 용광로 폭발 반경 최대+35%, 300초부터2→3개. 발생 간격 최대20% 단축, 피해 최대25% 증가. 기존1.5/1.6초 예고·위험 구역6개 상한·공통 이벤트 비중첩 유지. 외곽 고리는 별도 지형 위험을 추가하지 않는다. |
| 9. 후반 선체 감소 | 300~480초 모든 재생/즉시수리 효율을100→30%로 점진 감소, 이후30%. 기본/강화 재생·나노봇·수리 보급·회복 강화·구형 회복 블록에 같은 배율. 최대 재생7.25+A나노봇10도8분부터5.175HP/초로 붕괴 완화 중 약5.247HP/초보다 낮다. 즉시 수리로 잠시 버틸 수 있지만 재생으로 손실을 완전히 막을 수 없다. 상단/강화 화면에 효율, 도감에 기본값/후반 규칙을 표시한다. |
| 10. 방향 기호 | 긴 축과V촉 화살표로 목적 방향을 명확히 표현. 정예는 마름모, 지휘체는 조준원, 보급은 사각 상자+종류, 파츠는 고유 모듈 아이콘을 함께 표시. 화면 밖 보급/파츠도 같은 기호 사용. |
| 11. 미션 HUD | 좌하단 패널을 우상단(866,136)366×86으로 이동. 등급/이름·진행/시간·보상·막대를 세 줄로 표시. 중앙 전투와 좌하단 영역을 비우며 이벤트 안내는 상단 중앙512px로 맞춰 겹침을 피한다. |
