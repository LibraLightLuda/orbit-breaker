## 3.18.3 모바일 조작과 화면 배치 (2026-10-13 우선 규칙)

메인·출격 준비·레벨업 선택은 가로·세로 모두 스크롤 없이 한 화면에서 선택한다. 출격 준비의 기체·전장·난이도 선택은 위치를 유지하며 진입 애니메이션을 반복하지 않는다. 작은 화면에서는 중복 미리보기와 장식 대신 모든 실제 선택지·효과·진화 조건을 우선한다. 이후 선택 UI에도 스크롤 없이 비교할 수 있는 배치를 우선 적용한다. 목록형 도감·기록의 긴 정보는 기존 페이지/스크롤 구조를 유지한다.

모바일은 드래그로 이동하며, 0.3초 이상 누르고 화면 픽셀 기준 48px 이상 끌었다 놓으면 처음 누른 지점에서 놓은 지점으로 향하는 벡터로 돌진한다. 짧은 드래그는 이동만 한다. 단일 탭은 스킬을 소비하지 않으며, 0.24초 내 52px 이내의 두 번 탭은 충전된 오버드라이브를 발동한다. 취소된 터치/메뉴 전환/초점 손실은 스킬을 발동하지 않는다. 하단 즉시 스킬 버튼과 데스크톱 좌클릭/Space·우클릭/E는 유지한다.

화면 밖 파츠·아이템은 공통 가장자리 화살표와 아이콘, 거리, 남은 수명, 잠금 상태로 안내한다. 중앙의 중복 최근접 안내는 제거한다. 모바일에서는 상단 HUD와 하단 스킬 영역을 피하고 화면 픽셀 크기로 렌더한다. 전투 규칙·데이터·밸런스·저장·고스트 형식은 변경하지 않는다.

## 3.17 플레이 피드백

우측 상단의 기존 영역 안에서 업적 달성·도감 해금·무기 진화·기체 진화를 색과 도형이 다른 알림으로 3초씩 순서대로 표시한다. 이미 보유한 업적/도감은 재공지하지 않으며 무기 진화와 기체 I/II 진화는 출격마다 각각 알린다. 누적 업적은 과거 기록과 현재 출격의 진행을 합쳐 달성 즉시 저장하며 결과 통계에는 출격을 한 번만 더한다. 점수/경험치 채널은 알림 아래에 고정하고 마지막 획득 수량·당시 배율·단계점을 다음 획득까지 계속 표시한다. 효과 줄이기에서는 맥동을 제거한다.

전체 상단 배경 불투명도는12%이며 보조 패널도12%, 일시정지 버튼 배경은8%다. 글자·기호·게이지는 읽을 수 있게 유지한다. 일시정지 버튼은28×28 아이콘이며 ESC도 유지한다.

Windows 저장은 배포 폴더/제품 표시 이름/버전과 독립된 `%APPDATA%/OrbitBreaker/profile/`에 둔다. `records_v2.json`, 정상 백업과 연결된 고스트 파일을 함께 유지한다. 기존 Godot 앱 데이터의 Orbit Breaker · 오빗 브레이커 폴더 또는 이전 user:// 기록은 새 프로필이 없는 최초 실행에만 복사한다. 고스트와 기록의 SHA-256 일치 확인 후 새 기록을 확정하며 원본은 보존한다. 복사 실패/복구 불가능한 손상이 있으면 새 기록 저장을 중지하고 기존 기록을 보여준다. 새 프로필이 이미 있으면 오래된 버전의 기록으로 덮어쓰지 않는다. 웹은 기존 브라우저의 사이트 저장소를 사용하며 사이트 데이터 삭제/다른 출처/다른 브라우저에는 이어지지 않는다.

좌클릭 돌진 완료 시 실제 기체 끝점과 현재 카메라/창 변환에 맞춰 Windows 커서를 이동한다. 사용자가 다시 마우스를 움직일 때까지 커서 이동을 멈춰 이전 위치로의 역주행을 방지한다. 재사용 대기 중 클릭은 커서 이동을 예약하지 않으며 Space 돌진·키보드 이동은 기존 동작을 유지한다. 웹은 브라우저에서 OS 커서 이동을 지원하지 않아 실제 커서를 잠시 숨기고 끝점 조준표를 표시하며, 마우스를 움직이면 정상 커서와 이동을 복원한다.

## 3.16 그래픽 중심 통합 HUD

좌측 상단에 선체 수치·체력 막대·방향이 있는 순재생/붕괴 게이지·재생/전체 손실 수치·수리 효율·추진 비율/분절 게이지를 모은다. 손실 수치에는 외곽 손상을 포함한다. 중앙 상단에는 시간/목표·전장/현재 지역·위험 단계점·전투/이벤트 상태·기체 특성과 미션 등급/목표/남은 시간/진행 막대를 통합한다. 미션 보상은 강화 개수만큼 마름모와 파츠 기호로 표시한다. 자세한 미션 조건은 ESC에서 확인한다.

우측 상단에는 누적 점수·처치 수와 고정된 두 보상 채널을 둔다. 점수는 금색 육각, 경험치는 청록 마름모이며 획득한 최종 숫자를 크게 표시한다. 활동영역의 기본 보상도 표시한다. 외곽 보상은 획득 순간의 배율 숫자와 금/적/보라색·1/2/3단계점으로 구분한다. 전투 중에는 위험지역 보상의 긴 설명이나 배율 표를 띄우지 않는다. 같은 종류/배율의 연속 보상은 합산하고 표시 수명을 갱신한다. 지역 전환 후에는 새 보상으로 교체하여 이전 배율이 잘못 보이지 않게 한다. 효과 줄이기에서는 이동·맥동 없이 숫자·기호·배율을 유지한다. 보상 계산·위험 손상·저장/고스트 형식·조작은3.15를 유지한다.

## 3.15 위험 탐사·성장·후반 압박

11개 피드백의 수치와 검증 범위는 GAMEPLAY_FEEDBACK_3_15.md를 따른다. 미션 패널의 현재 배치는 위3.16 통합 HUD를 따른다. 횟수는 정수, 시간만 소수로 표시한다. C/B는 파츠 없이 추가 강화1/2회, A는 강화3회+파츠1개다. 파츠는 A미션 또는 깊은 외곽 탐사에서만 나온다.

레벨업 요구 경험치는9+4×(레벨−1)+0.7×max(0,레벨−10)^2다. 안전/외곽1/2/3층 경험치·처치점수 배율은1/1.25/1.6/2.1이며 기체의 지급 시점 위치를 따른다. 필드 경험치 자체에는 배율을 저장하지 않아 이중 적용하지 않는다. 처치 추가 보너스에도 적용하며 경험치300개 상한의 즉시 지급도 같은 규칙이다. 좌측 계기판에 실제 전체 손실·추진 비율을 표시하고 우측 보상 채널의 최종 보상 수량/배율 숫자는 효과 줄이기에서도 유지한다.

150초부터 모든 적의 추가 압박S=1+1.8×clamp((t−150)/450,0,1)^1.4+min(0.45,장착 파츠수×0.025). 체력×S, 피해×S^0.25, 속도×S^0.12를 기존 배율 위에 적용한다. 살아 있는 적도 남은 체력 비율을 보존하며 같은 최종배율로 갱신한다. 번개 폭은10분까지최대45% 증가, 동시 통로는240초2개·480초3개. 용광로 반경최대35% 증가·300초부터3개 폭발. 발생 간격최대20% 단축, 피해최대25% 증가. 기존 예고와6개 위험 상한은 유지한다.

5~8분 모든 재생/즉시수리 효율은100→30%로 감소하고 이후30%다. 기본/강화 재생·나노봇·응급수리·회복 선택·구형 회복 블록에 동일 적용한다. 상단에 현재 효율을 표시한다. 최대 재생+A나노봇도8분부터5.175HP/초로 완화중 붕괴약5.247HP/초보다 낮아 무피격이어도 감소한다. 즉시수리는 유효하지만 항구적 손실 방지는 불가능하다. 방향 표시는 긴 화살표와 정예 마름모/지휘체 조준원/보급 상자/파츠 모듈을 함께 사용한다.

## 3.12 선택 미션·탐사·기체 테크트리

활동영역은 주 전투 공간이고 외곽은 짧게 위험을 감수해 추가 성장을 회수하는 공간이다. 기존 외곽 손상·노출·복귀 흐름·회복 경제는 유지한다. 모든 새 시간은 전투 시간이며 일시정지·강화 선택·도감에서는 정지한다.

### 고정 거리 돌진

좌클릭/Space는 발동 시 커서 방향을 고정하고 940px/s로 0.20초, 총188px를 추진한다. 가까운 커서나 일반 이동의 정지 범위 안을 클릭해도 같은 거리다. 정확히 기체 중심을 클릭해 방향을 계산할 수 없으면 현재 기체 방향으로 돌진한다. 좌클릭은 키보드 이동 중에도 커서 방향을 사용한다. Space는 활성 마우스 방향, 없으면 키보드 이동/기체 방향을 사용한다. 카메라 이동량을 보정한다. 돌진 중 새 이동 입력이나 커서 이동으로 방향을 바꾸지 않는다. 외향 돌진의 별도 감속은 제거한다. 블랙홀과 외곽의 연속 인력/복귀 흐름은 별도로 작용하므로 실제 지상 변위는188px와 다를 수 있다. 무적·피해·재사용 시간·스카우트 후속 추진은 유지한다.

### 매분 선택 미션

첫 미션은00:50 공개,01:00 시작,01:50 마감이다. 다음은01:50 공개,02:00 시작,02:50 마감으로 반복한다. 매분의00~50초가 수행 구간,50~60초가 다음 미션을 미리 보는 휴식 구간이다. 첫50초는 조작·성장 적응 시간이다. 한 번에 한 미션만 배정하며 동일 종류가 연속되지 않는다. 미션 전용 난수는 기존 전투·아이템 난수와 분리한다. 첫 미션에서는 아직 드문 포격수 사냥을 제외한다.

등급은 C/B/A 균등 무작위다. 회피 미션의 붕괴·외곽 지속 손상은 피격 횟수에 포함하지 않고, 무적으로 막은 공격도 포함하지 않는다. 외곽 정찰은 누적 시간이라 여러 번 짧게 다녀올 수 있지만 마지막에는 활동영역 복귀가 필요하다. 최대 요구7초이며 2층에 머무르라는 요구는 없다. 미리 공개된10초 동안의 활동은 집계하지 않는다. 마감 시각 이후의 처치는 이전 목표에 들어가지 않는다. 처치/횟수 목표는 달성 즉시 성공, 생존 목표는 마감까지 기다린다. 일찍 완료해도 다음 미션 시각은 당겨지지 않는다. 회피 한도 도달·사망·시간 초과는 실패이며 점수/선체/파츠 페널티가 없다.

강화는 경험치/레벨을 소비하거나 레벨 수치를 올리지 않는 추가 선택권이다. 여러 선택권과 정상 경험치 레벨업이 겹치면 추가 선택부터 순서대로 처리한다. 기존 회복 선택 보장·강화 한도·무기 진화는 동일하다. 파츠는 기체 근처의 실제 회수 아이템으로 지급하며 획득해야 장착한다. 성공 보상은 중복 지급하지 않는다.

중앙 통합 패널에 등급·종류·남은 시간·숫자 진행·진행 막대·보상 기호를 표시한다. 상세 목표는ESC에서 확인한다. 예고/시작/성공/실패에 소리와 상태 전환을 제공하며 성공은 초록 체크·충격 고리, 실패는 붉은 종료 문구다. 효과 줄이기에서도 필수 목표/상태/막대/방향 표시는 남는다.

## 이동과 우주 배경

- 마우스 커서 방향으로 자동 이동한다. 커서까지 40px 이내에서 감속하고 10px 이내에서 멈춘다. WASD/방향키 입력이 있으면 키보드가 우선한다.
- 전장 밖 커서도 추적하며, 창 밖에서는 데스크톱 커서 좌표를 게임 좌표로 변환하여 추적한다. 다른 앱으로 포커스가 옮겨지면 자동 일시정지한다. 강화 선택·일시정지 종료 후에는 새 마우스 이동 이벤트부터 조종하여 카드 클릭 위치로 갑자기 이동하는 것을 막는다.
- Space 또는 좌클릭으로 대시, E 또는 우클릭으로 충전된 오버드라이브를 발동한다. 버튼이 처리한 클릭, 버튼 해제, 전투 외 화면의 클릭은 스킬을 발동하지 않는다.
- 세 깊이의 별이 서로 다른 속도로 흐른다. 배경 이동은 기체 속도를 360px/초로 제한한 뒤 0.12배, 지수 보간 계수 `1-exp(-7dt)`로 완만하게 반영한다. 대시의 시작·종료 때 배경이 갑자기 당겨지는 것을 줄인다. 전투 일시정지·강화 선택·도감에서는 배경도 멈춘다. 효과 줄이기를 켜면 움직이는 배경을 고정한다.
- 중앙 25% 구역은 기본 속도다. 원 중심에서 안전 반지름까지 거리를 정규화한 후 부드럽게 감속한다. 가장자리 속도 하한은 시작 100%, 150초 90%, 300초 80%, 450초 70%, 600초 60%다. 이는 원래 속도의 비율이다.
- 추진기 강화는 회당 +28 (기존 +18), 최대 4회다. 돌진은 커서 방향으로 고정된188px를 추진한다. 외곽 복귀 흐름과 인력은 별도로 적용한다.

## 원형 궤도와 세 외곽층

3.5에서는 3.4의 전체 원형 전장을 **반지름·지름 기준 80%**로 줄인다. 중심은 (640,386), 활동 반지름 R = sqrt(1136×516×2/π)×0.8 ≈ 488.70px, 지름 약 977px. 외곽층 폭은 각 144px, 총 432px이며 전체 외곽 반지름은 약 921px다. 면적은 3.4의 64%다. 기체 크기·이동 속도·피해 강도는 유지해 경계에 더 빨리 닿고 위험 구역을 이동 판단에 활용하게 한다. 기체 중심의 안전 반지름은 R-13이다. 물리 벽·위치 고정·순간이동 없이 복귀 흐름과 손상으로 궤도 안에 머물게 한다.

Windows 기본 창은 1600×900이다. 기준 화면 1280×720, 최소 창 960×540이며 화면 비율에 따라 전장을 확장한다. 검은 여백 없이 화면 전체를 채우고 도형·글자 비율을 유지한다. 메뉴·HUD·마우스 좌표는 중앙 기준 화면에 맞춰 정렬한다. 창 크기 변경과 F11 전체 화면을 계속 지원한다. 웹은 브라우저 공간에 맞춰 표시한다.

층 깊이 q = clamp((중심 거리-(R-13))/144, 0, 3), 연속 노출 시간 s(초). 피해는 q≤1에서 q×(4+0.25s), 1<q≤2에서 4+20×smoothstep(0,1,q-1)+lerp(0.25,0.6,q-1)×s, q>2에서 24+96(q-2)+lerp(0.6,2,q-2)×s다. 층 사이 피해는 연속이며, 방벽·무적·오버드라이브·난이도 피해 감소를 우회한다. 2층 중간에서 4초간 원주 방향으로 이동해도 일반 선체가 생존하는 것을 검사한다.

안전 반지름 초과 거리/432을 d라 할 때 중심 방향 복귀 흐름은 40×min(1,1.5d)² +1760×max(0,3d-2)³ px/초다. 2층까지 완만하고 3층부터 강해진다. 세 번째 층의 바깥에서는 외향 대시도 되돌린다. 안쪽/외향 돌진의 추진은940px/s로 동일하며 복귀 흐름은 별도로 적용한다. 외곽 깊이 0.08(약 35px) 이상 진입한 뒤 안전 원으로 돌아오면 귀환 1회다. 복귀 즉시 추가 피해가 사라지고 다음 전투 갱신에서 노출 시간이 초기화된다. 일시정지·강화·도감 중에는 노출과 전투가 멈춘다.

청록 활동 경계 → 금색 → 붉은색 → 보라색을 같은 간격의 부드러운 광륜으로 표현한다. 경계 중심 양쪽36px에 걸쳐 빛이 흐려진다. 색조·화면 가장자리 위험 빛·중심 방향 화살표, 중앙 지역/단계점, 좌측 손실/추진 계기판, 우측 획득 보상으로 상태를 전달한다. 중앙에서 가로 ±240px, 세로 ±100px를 넘어가면 카메라가 따라가며 HUD는 고정한다. 마우스 목표에 카메라 이동량을 반영한다.

효과 줄이기를 켜면 장식 맥동과 별 이동을 멈춘다. 필수 경계·방향 화살표·충전량·카메라 추적은 유지한다.

## 외계 침공과 적

일반 적은 활동 원 안에 생성되지 않는다. 무작위 방향의 해당 외곽층에서 출현하여 플레이어를 향해 이동한다. 층 경계에서 최소 32px 안쪽 여유를 두며, 기체로부터 180px 미만의 위치가 뽑히면 반대편에 생성한다. 강적은 3층보다 바깥에서 경고와 함께 등장해 원 안까지 천천히 접근한다. 원 안 진입 전 이동 속도는 기본의 70%다. 생성은 순간이지만 실제 등장 위치에서 이동하며 플레이어 근처로 순간이동하지 않는다.

## 모든 전장의 공통 이벤트 (3.11)

외곽 고리·번개 회랑·잔해 용광로 모두 공통 이벤트가 발생한다. 전장 고유 통로/포격의 기존 짧은 예고와 별도로, 모든 공통 이벤트는 **발생 10초 전** 알람·고정된 발생 위치/범위·카운트다운·대응법을 표시한다. 마지막 3·2·1초에도 알람을 울린다. 화면 밖의 중심은 방향 화살표와 거리로 안내한다. 일시정지·강화·도감에서는 경고/진행 시간이 흐르지 않는다. 효과 줄이기에서도 필수 범위·카운트다운·충격파·피격 표시는 남는다.

## 스킬과 실시간 표시

돌진은 기체별 실제 재사용 시간과 대시 강화가 적용된 시간을 기준으로 0→100% 충전된다. 사용 순간 비워지고, 강화 선택·일시정지 중에는 차오르지 않는다. 오버드라이브는 기존 규칙대로 일반 처치 +2, 정예/보스 +12로 최대 100 충전하며, 자동 시간 충전은 없다. 100에서 우클릭/E로 발동하면 6초간 화력 ×1.45 및 받는 전투 피해 ×0.55, 사용 중에는 남은 지속 시간을 표시한다.

하단 스킬 패널과 안내 텍스트를 제거한다. 기체 아래 좌우 25px, 아래 37px에 작은 게이지 두 개를 배치한다. 왼쪽 초록은 돌진, 오른쪽 금색은 오버드라이브이며 가운데 마우스 그림의 왼쪽/오른쪽 버튼을 밝혀 입력을 표시한다. 완충 시 윤곽이 모두 채워지고 빛이 약하게 반짝인다. 사용 중 오버드라이브는 남은 지속 시간만큼 줄어든다. 기체와 무관하게 좌클릭 돌진은 초록 삼각 윤곽, 우클릭 오버드라이브는 금색 원형 윤곽이다. 삼각형과 원형 모두 24구간으로 충전량을 표시한다. 효과 줄이기에서는 정적으로 표시한다. 조작법의 전체 설명은 도움말에서 확인한다.

선체 게이지는 순변화 ‘재생-붕괴-외곽 피해’를 기준으로 양수는 오른쪽 초록, 음수는 왼쪽 빨강이다. 추진 게이지는 실제 프레임 이동 속도/강화 포함 기본 속도이며 정지·대시·감속도 반영한다. 숫자와 문구를 함께 제공하고 보간 계수 1-exp(-10dt)로 완만하게 갱신한다.

## 체력 경제

수리 효율 적용 전 기본 재생1.00HP/초, 자가 수리는선택마다+1.25HP/초·최대5회(합계7.25)다. 선체 보강은최대 체력+35·기본70회복·최대4회다. 영구 회복 강화가모두 최대면 반복 가능한긴급 정비(기본80회복)를 제시한다. 모든 재생·즉시 회복에5~8분100→30% 수리 효율을 적용한다. 최대 선체 증가는 감소시키지 않는다. 매번3개 중회복 계열 최소하나를 보장하며 위치는 무작위다.

레벨업 무료 회복, 무작위 회복 드롭, 보스·정예 처치 무료 회복은 제거했다. 처치의 경험치·점수·오버드라이브 충전 보상은 유지한다. 5분 이전의 회복 투자 필요성은 유지한다. 5분 이후는 주기적 붕괴 완화와 보스 보상으로 공격/진화 선택을 병행할 수 있다.

붕괴는 대시 무적·피격 무적·오버드라이브·여유 난이도의 전투 피해 감소를 우회한다. HP 0에서 먼저 종료 처리하므로 같은 프레임의 회복으로 부활하지 않는다. HUD에 재생, 붕괴, 순변화, 이동 속도 비율을 실시간 표시한다.

아이템을 제외하고 적에게 전혀 맞지 않는 조건에서도 모든 함선과 난이도에서 회복 0회 또는 1회만으로 300초에 도달할 수 없음을 검사한다. 1회 자가 수리는 시작부터 주어 최선의 누적 회복을, 선체 보강·긴급 정비는 충분히 피해를 받은 후 적용해 회복량을 낭비하지 않는 조건을 사용했다. 3회 자가 수리를 갖춘 스트라이커는 무피격 조건에서 5분 생존이 가능하다. 실제 전투에서는 피격과 선택 시점에 따라 더 많은 회복이 필요하다.

## 5분 돌파 이후

보스 처치와 300초 생존을 달성하면 돌파 보너스를 한 번 지급하며 전투는 계속된다. 이후 사망해도 돌파 성공으로 기록한다. 보스를 처치하지 못했다면 5분 이후에도 전투가 계속되며, 이후 처치 시 돌파가 인정된다. 보스 미처치 종료는 실패다.

5분 이후 붕괴 기본 피해는 완만하게 증가한다. 6분 기본 7.10/초, 8분 9.54/초, 10분 직전 약13/초이며, 매분 첫20초는 45% 완화한다. 5분부터 정예 증원을 반복하며 간격은35초에서20초까지 점진적으로 짧아진다. 돌격/포격형을 교대로 생성하고 동시에 살아 있는 정예는2기까지다. 증원 정예 체력은 기존 시간별 체력에 ×(1.25+0.25×floor((경과초-300)/60))를 적용한다. 돌격형 속도는×1.18, 포격형은×0.9다. 첫 추격 지휘체는330초에 등장하고 이후 간격은50초에서35초까지 점진적으로 짧아진다. 첫 지휘체 처치 여부와 무관하며 동시에 살아 있는 지휘체는2기까지다. 가득 차면 다음 빈자리가 생길 때 한 기만 생성하며 밀린 여러 기를 한꺼번에 만들지 않는다. 격파로 증원 시각을 늦추지 않는다. 5분 이후 생성되는 모든 적은 분당 속도+4%, 접촉/탄환 피해+8%, 탄속+2.5%를 적용하며 일반 적의 기존 시간별 체력 증가도 유지한다. 후반 강적의 심우주 접근 속도는×2.8이며 플레이어와420px 이내 또는 활동영역에 진입하면 기존 전투 속도로 복귀한다. 예고·경보와 동시 적탄 상한은 유지한다. 추격 n번째 체력은3600×(1+0.35n)×난이도×추가압박S, 속도는×(1+0.08n), 접촉/탄환 피해는×(1+0.12n), 탄속은×(1+0.08n)다. 기존 전장별 예고 패턴/체력 절반 격앙을 유지한다. 300초 이후 지휘체 격파 시25초간 붕괴를45% 완화하고, 추가 점수1800+600n/경험치35+10n을 지급한다. 시간별 완화와 중첩하지 않으며 외곽/전투 피해는 줄이지 않는다. 고정 무료 회복은 추가하지 않는다. 최종 600초에는 HP를 0으로 만들어 우주 완전 붕괴로 종료한다. 이 종료는 비정상적으로 큰 체력·재생이나 무적도 무시한다. 제한은 실제 전투 시간 기준이므로 선택·일시정지 시간은 포함하지 않는다.

## 기체별 고유 전투 방식 (3.10)

스트라이커는 체력 100/속도 218/대시 3초/위성 3/화력 100%, 스카우트는 80/255/2.45초/3/90%, 배스천은 140/185/3.35초/4/95%다. 출격 준비에 효과와 조건을, 전투 HUD에 현재 조준·가속·방벽 재충전을 표시한다. 기체에 쌍포/5칸 조준 표시, 후퇴익/추진 흔적, 장갑/방벽 원을 각각 그려 구분한다.

| 기체 | 고유 능력 | 추천 플레이 |
| --- | --- | --- |
| 스트라이커 · 조준 고정 | 정지 입력으로 1.2초 충전하며 자동포 피해 최대 +60%. 일반 이동 입력 시 초당0.4 감소해 완충에서3초 후 소진한다. 돌진 중 충전량 유지, 실제 전투 피격 시 초기화. 위성/보조 무기는 보너스 제외. 강화·정지·도감 중 충전/감소 정지 | 안전한 곳에서 정지해 스택을 쌓고 이동하며 집중 포격한다. |

피격 무적 중의 공격·0 피해는 방벽을 소모하지 않는다. 회복·붕괴·외곽 피해 규칙은 바꾸지 않는다. 방벽은 환경 피해를 막지 않으며, 모든 고유 타이머는 강화 선택·일시정지 중 멈춘다. 재출격 시 고유 상태를 초기화한다.

기존 랭킹·업적·설정·고스트는 보존한다. 랭킹 점수는 초기화하지 않으므로 이전 버전과 3.7의 서로 다른 기체·공간 밸런스에서 획득한 기록이 함께 표시된다. 기존 비행 경로 고스트를 계속 읽으며, 새 기록은 기체 고유 능력을 포함한 전장 시각 상태를 저장한다.

## 고스트 관전

전투 시간 기준 최대 초당5회, 최대3002프레임으로 기체 위치·방향·선체·점수·위성·돌진·오버드라이브와 전장 전체 시각 상태를 기록해 랭킹 최고 기록과 연결한다. 적(정예/보스 포함)의 출현·위치·선체·사격 예고·감속/마비, 아군/적군 탄환과 유도탄, 아이템 종류·등급·위치·남은 수명, 경험치와 회복 블록, 전기 통로·폭발 위험, 번개/폭발/피격/획득 효과, 무기 강화·진화·일시 버프·기체 고유 능력의 상태를 저장한다. 같은 개체의 위치는 고유ID로 스냅샷 사이를 보간하고 서로 다른 개체를 연결하지 않는다. 생성·제거는 매 전투 프레임의 시각과 개체 상태를 별도로 기록하여0.2초보다 짧게 출현한 적·탄환·아이템·효과도 관전 중 해당 시점에 표시한다. 위치의 기본 기록은0.2초 간격이고 피해/버프 수치의 이산 변화는 정기 기록 시점에 반영된다. 동영상처럼 모든 렌더 프레임을 저장하지는 않는다.

일시정지·1/2/4배속·처음부터·타임라인 앞뒤 탐색을 제공한다. 임의 시점의 상태를 별도 관전용 모델에 복원하여 실제 게임과 같은 렌더러로 그린다. 전투 규칙을 다시 실행하지 않으므로 관전으로 적 처치·아이템 획득·업적·횟수·점수·영구 저장을 발생시키지 않는다. 정지 중에는 보스 회전도 멈춘다.

새 형식v2는 OBG2 헤더와 gzip 압축JSON을 사용한다. 읽을 때 압축 파일32MB·해제 데이터256MB·프레임/개체 수·필드 타입·유한 좌표·아이템/버프/진화ID를 검증한다. 파일 쓰기는 임시 파일 후 교체한다. 기존v1 JSON/13열 고스트는 그대로 읽어 ‘이전 기록·비행 경로 전용’으로 표시한다. 과거 기록에 없는 적/아이템을 역으로 복원할 수는 없다.

손상된 고스트는 관전을 거부하되 순위는 보존한다. 저장 완료 뒤 현재 기록과 복구 백업이 참조하지 않는 고스트만 정리한다. 저장 실패 시 진행도를 되돌린다.

## 배포·웹·저장

현재 배포 위치와 검증 상태는 VALIDATION_V3.md를 따른다. 최신 검증 완료 한 세대만 유지하며 ARTIFACT_RETENTION.md의 절차를 따른다. 기존 records_v2.json에 항목을 추가하며 실제 플레이어 저장은 배포 정리 대상이 아니다.

단일 스레드 Web 내보내기를 GitHub Pages에서 제공한다. 서버·계정·온라인 통합 순위는 없다. 웹 기록은 현재 브라우저에만 저장하며 Windows/다른 기기와 공유되지 않는다. 시크릿 모드·사이트 데이터 삭제·브라우저 저장소 정책으로 기록을 잃을 수 있다. 웹은 탭 내 마우스/키보드 조작을 지원하며 운영체제의 창 밖 커서를 조회하지 않는다. 데스크톱 키보드·마우스가 대상이다.

## 기획 범위와 배포 원칙

MVP의 한 판 생존/성장/재도전과 2.0의 기체·전장·무기 진화를 위의 현재 규칙으로 통합했다. 과거의 한 화면 사각 전장·즉시 승리 종료·최신과 직전 두 세대 보관은 현재 규칙으로 사용하지 않는다. 온라인 통합 순위·계정·멀티플레이·결제·모바일 배포는 현재 범위에 포함하지 않는다.

게임 소스와 플레이어 기록을 보호하며, 검증된 최신 배포본 한 세대의 실행 파일·체크섬·안내·대응 증거만 보관한다. 새 후보의 필수 검사·내보내기·실행 확인이 성공해야 역할을 갱신한다. 구자료 정리가 차단되면 위치와 사유를 명시하며 완료로 표시하지 않는다. 자동 검사·실제 실행/표시·사람의 재미/밸런스 평가는 각각 다른 증거로 보고한다.

## 3.6 자동 발동 아이템

장비/경험치 강화와 별개인 일회성 희귀 보급이다. 수집 반경 30px이며 돌진 경로를 통과해도 자동 획득한다. 추가 버튼·인벤토리는 없다. 전장에는 최대 12개, 35초 유지. 등급은 C(청록), B(보라), A(금색)이며 등급 글자·고유 아이콘·잔여 수명으로 구분한다. 가장 가까운 보급의 방향·거리·등급·위험 여부를 HUD에 표시한다. 일시 버프는 화면 하단에 고유 아이콘·이름·등급·남은 시간을 표시한다.

| 종류 / 아이콘 | C | B | A |
| --- | --- | --- | --- |
| 출력 코어 / 포탑 | 모든 무기 피해 +30%, 10초 | +60%, 10초 | +100%, 10초 |
| 추진 연료 / 이중 화살표 | 일반 이동 +20%, 10초 | +35%, 10초 | +50%, 10초 |
| 속사 회로 / 3개 탄선 | 자동포 공속 +30%, 10초 | +55%, 10초 | +90%, 10초 |
| 수리 나노봇 / 고리 십자 | 재생 +3HP/초, 10초 | +6, 10초 | +10, 10초 |
| 응급 수리 / 십자 | 최대 선체 25% 즉시 회복 | 45% | 70% |
| 정지장 / 격자 | 220px 내 1.5초 마비 | 320px, 2.5초 | 440px, 4초 |
| EMP 폭탄 / 방사원 | 180px 내 피해100·적 탄환 제거 | 250px, 피해220 | 340px, 피해450 |
| 광전 회로 / 번개 | 자동포 공속 +80%, 4초 | +150%, 4초 | +300%(4배), 5초 |

범위 효과는 획득 순간 기체 중심이다. 정지장은 이동·사격 예고·돌진 타이머를 함께 정지시키며 이미 날아오는 탄환과 접촉 피해는 남는다. 정예·보스 마비 지속시간은 35%로 줄인다. EMP 피해는 고정이며 출력 강화로 추가 증폭되지 않는다. 선체 회복은 최대값을 넘지 않으며 재생도 10분 강제 붕괴를 막지 못한다.

같은 종류의 일시 버프는 수치 합산 없이 동급/상위 획득 시 새 수치·기본 지속시간으로 갱신한다. 하위 획득 시 기존 버프의 수치·남은 시간을 유지한다. 속사·광전은 더 큰 공속 수치 하나만 사용한다. 서로 다른 출력·추진·재생 버프는 함께 적용되며, 기존 강화/오버드라이브와 결합된다. 모든 버프·보급 시간은 전투 시간 기준으로 정지/도감/강화 선택 중 멈추며 새 출격 시 초기화한다.

- 첫 자연 보급은 48초, 이후 55~75초 간격. 절반은 안전 구역, 절반은 외곽1~2층에 생성한다.
- 일반 적 처치: 0.6% 드롭, 성공 후 14초간 일반 드롭 제한. 강적 확정 드롭과 자연 보급은 제한 대상이 아니다.
- 안전 구역 등급: C80% / B18% / A2%. 외곽1층: C20% / B65% / A15%. 외곽2층 이상: B60% / A40%.
- 정예 처치: B80% / A20% 확정 1개. 보스: A 확정 1개. 강적이 너무 먼 곳에서 사망하면 외곽2층의 회수 가능한 위치로 드롭을 당긴다. 전장이 가득 차면 가장 오래된 보급을 새 보상으로 교체한다.
- 종류는 8종 균등 추첨. 아이템 전용 난수 생성기로 기존 적/강화 추첨과 분리한다.

### 발견 도감과 업적

메뉴/일시정지의 기존 도감에 ‘무기 진화 / 아이템 도감’ 탭을 둔다. 미획득 종류는 이름·아이콘·효과를 물음표로 감추고, 해당 종류를 한 번 획득하면 C/B/A 효과를 모두 공개한다(발견 단위는 등급이 아닌 8종). 발견·획득 횟수·A등급 획득·경계 회수는 획득 후 즉시 기존 로컬 저장에 안전하게 병합한다. 저장 실패는 표시하고 재시도하며, 미저장 발견이 있으면 새 출격으로 덮어쓰지 않는다. 구버전 기록·설정·업적·해금은 보존하고 새 도감만 미발견으로 시작한다.

기존 40개에 보급 획득 1/10/50, A등급 1/5/20, 경계 회수 1/5/20, 8종 발견을 더해 총 50개 업적이다. 기존 점수 방식에 따라 영구 업적 점수를 부여하며 동일 업적은 중복 지급하지 않는다. 획득 업적은 즉시 저장되고 결과 저장 시 획득을 다시 합산하지 않는다.

## 3.7 경계 보급의 복귀 흐름

경계 또는 안전 구역 가장자리24px 안에 있는 경험치·회복 블록과 아이템은 전투 시간 기준 초당18px로 중앙 방향으로 이동한다. 활동 반지름에서 기체 반지름과24px를 뺀 위치(중심 거리 약451.7px)에 도달하면 멈추며, 중앙까지 모두 모으지는 않는다. 방향에 관계없이 같은 속도이고 순간이동·등급 재추첨·경험치 지급을 일으키지 않는다. 기존 경험치 수집 자석은 복귀 흐름과 함께 작동한다. 아이템 수명35초는 계속 감소하고 경계 회수 업적은 실제 획득 위치가 경계 안일 때만 집계한다. 일시정지·도감·강화 선택 중에는 복귀 흐름도 멈춘다. 리플레이에는 이동한 실제 보급 위치를 기록한다.

## 3.8 성능 및 고스트 저장

탄환 충돌은128px 공간 격자와 이동 구간의 사각형으로 후보를 좁힌 뒤 기존 선분 충돌을 검사한다. 관통탄은 개체별 고유 ID로 중복 타격을 막는다. 위성 좌표는 프레임당 한 번 계산하며 난이도 정보는 출격 때 보관한다. 화면 밖 일반 객체는 그리지 않고 HUD 글자 갱신은10Hz로 제한한다. 전투/입력/게이지의 물리 갱신은60Hz를 유지한다.

전장 고스트의5Hz 스냅샷/매 물리 프레임 생성·제거 이벤트를 유지한다. Windows는 압축·검증·메모리 해제를 별도 스레드로 처리한다. 새 OBC3은 최대4프레임 JSON/GZIP 묶음과 완료 표시를 갖는다. 단일 스레드 웹은1프레임씩 처리한다. 점수는 먼저 원자 저장하고, 완성 파일만 랭킹에 연결한다. 저장 중 재출격할 수 있으며 앱 종료 시 Windows 작업을 회수한다. 강제 종료/웹 탭 종료 때 미완성 고스트는 연결하지 않는다. 기존13필드 비행 경로와 OBG2 전장 기록을 읽는다. 압축32MB/해제256MB/묶음2MB/3002프레임 제한을 넘거나 저장에 실패하면 점수는 유지하고 고스트 미저장을 알린다. 기존 저장·설정·난수 종류/초기화·조작을 보존하며 선택지 보장 변경으로 같은 시드의 이후 선택/전투 결과는 달라질 수 있다.

## 3.10 상단 HUD

상단 배경 불투명도는48%(투명도52%)이며 전장 객체가 뒤로 비친다. 글자는 불투명하게 유지하고2px의 어두운 외곽선을 적용해 밝은 탄환/효과 위에서도 읽을 수 있게 한다. 돌진 삼각형/오버드라이브 원형과 확장 전체화면은 유지한다.
