## 필터와 모바일 해상도 결정

실제 네이티브 캡처에서 linear, linear+mipmap, nearest를 비교했다. mipmap 후보는 작은 선체가 더 흐려졌고 nearest는 회전 계단을 만들었다. 최종값은 **linear, mipmap 비활성**이다. `artifacts/current/filter-comparison.png`와 `filter-candidates/`는 실제 후보를 실행했을 때의 캡처다. 비활성화한 뒤 같은 화면을 후보 결과처럼 다시 만들지 않았다.

실제 WebAssembly QA를 390×844 CSS iframe에서 DPR 1 / 1.5 / 2로 실행했다. 모바일 최종값은 **DPR 1 유지**다.

| 강제 QA DPR | 실제 뷰포트 입력 검사 | 스트레스 p95 3회(ms) | 결정 |
| --- | --- | --- | --- |
| 1 | 7/7 | 23.9, 43.5, 44.4 | 채택 |
| 1.5 | 6/7 | 42.0, 24.8, 25.4 | 미채택 |
| 2 | 6/7 | 24.7, 42.8, 43.9 | 미채택 |

DPR 1.5와 2에서는 40 CSS px 드래그가 기존 48 CSS px 기준보다 짧은데도 돌진으로 처리됐다. DPR 1에서는 짧은 이동, 충분한 거리/홀드의 방향 돌진, 단일 탭/두 번 탭, 화면 버튼 검사가 모두 통과했다. 미채택 후보의 6/7은 실패 대조 결과이며 최종 배포본의 미해결 검사로 숨기지 않는다. QA HTML에만 강제 배율을 넣었고 배포 HTML에는 해당 옵션이 없다. 결과는 `dpr-decision.json`, `web-results.json`, 생산 스크립트/자산과 QA 사본의 일치 해시는 `web-source-equality.json`을 따른다.

이 Web 측정은 데스크톱 브라우저의 WebKit WebGL 어댑터를 사용했다. 프레임 시간이 크게 흔들리므로 모바일 60fps, 실물 장치 발열 또는 저사양 성능을 보증하지 않는다. 배율 1.5/2의 렌더 픽셀 수가 각각 약 2.25배/4배라는 비용은 텍스처 메모리 수치와 별개다. 실제 모바일 GPU 렌더 타깃 메모리와 발열은 측정하지 않았다.

## 게임 규칙·저장·검사의 정합성

`RunModel.PLAYER_RADIUS = 13.0`과 실제 공격/수집/탄 발사점·이동/돌진·난수·시간·보상을 유지했다. `run_model.gd`, `game_content.gd`, `save_store.gd`, `ghost_replay.gd`, `achievements.gd`, `touch_controls.gd`의 작업 전후 SHA-256이 모두 동일하다. 네이티브 플레이어 프로필도 실제 배포 실행 후까지 동일하다. `initial-baseline.json`과 최종 해시 검증으로 연결했다.

새 선명도 검사는 단순한 치수 일치에 머물지 않는다. 알파 여유·가시영역·피벗, 렌더 전후 모델/RNG 불변, 3기체×8창 크기의 실제 픽셀에서 가까운 적탄이 선체 위에 보이는지 검사한다. 실제 입력과 물리 진행 120프레임에서 이동과 시간 증가를 확인하고 4프레임마다 캡처한 30장을 이동 미리보기로 남겼다. 테스트 통과를 위한 체력/보상 증대나 결과 상수 대입은 하지 않았다. 선체 크기 52와 자산 대비 값은 시각 설계값이며 검사 결과나 성능 측정값을 대체하지 않는다.

성능 fixture는 전후 물리 처리에서 적 240·탄 240·경험치 300 부하를 보충하고 실제 유지 수를 확인한다. 초기에 경험치가 299로 줄어든 측정과 GPU 작업이 겹친 측정은 비교에서 제외하고, 동일한 보충 로직을 이전 Git 소스와 최종 소스에 적용해 독립 프로세스로 다시 측정했다. 원시 결과를 판정 함수가 읽어 10% 퇴행 기준을 계산한다.

브라우저 입력은 관찰한 버튼에 전달한 합성 DOM MouseEvent이며 실물 터치가 아니다. Web 오류 감시기는 엔진 bootstrap 이후 화면 렌더를 보기 전에 설치했고 관찰 중 오류는 0이었다. 브라우저 도구가 호출 사이에 페이지를 초기화하는 경우가 있어 전체 콘솔 이력을 연속 수집한 검사는 아니다. 별도 WebAssembly 뷰포트 입력 검사 7/7과도 구분한다.

## 확인하지 않은 범위

실물 휴대폰·Safari/iOS·저사양 장치·장시간 발열/전투/청취와 사용자의 최종 미적 수용은 확인하지 않았다. 자동 검사 수나 에이전트의 캡처 관찰은 사용자가 실제로 더 잘 구분하는지에 대한 최종 판단을 대체하지 않는다. 공개 사이트와 GitHub에는 이 선명도 개선판을 아직 반영하지 않았다.
