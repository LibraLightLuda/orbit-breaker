- 12개 진화, 23개 강화, 12개 보급, 파츠/조합, 미션/난이도/61개 업적 가족을 공유 도해 체계에 연결했다. 보급 C/B/A는 같은 컨테이너의 1/2/3분절·기존 색·문자로 구분한다. 정식 미발견 `?`는 유지한다.
- 외곽 고리·이온 회랑·잔해 용광로의 큰 공간 질감을 만들고 플레이 공간의 명도를 낮췄다. 행성, 강착 원반, 낙하체와 폭발·스파크·파동·추진은 새 표면을 사용한다. 실제 범위/시간은 기존 모델 데이터를 사용한다.
- 타이틀/출격 준비/전투/도감/강화/업적/결과/관전이 같은 자산을 쓴다. 구형 13필드 경로 고스트 분기도 새 기체·위성으로 바꿨다. Web 로딩 표면은 export preset에 넣어 재내보내기에도 유지한다.
- 강화 카드의 진화 연계 조건이 밖으로 넘치던 문제는 카드 내부의 제한된 스크롤 영역으로 해결했다. 조건·키보드 1/2/3·회복 보장·기존 메뉴 흐름은 유지했다.

의도적으로 남긴 절차적 도형은 활동 경계, 정확한 위험 범위, 충전·체력·진행 계기, 방향/상태 표식, 점수/경험치의 의미 부호, 실제 번개 연결선이다. 물체를 대신하던 MVP 다각형과 기능을 전달하는 기하 표식을 구분했다.

## 제작 수단 비교와 품질 수정

Blender 5.2.2 LTS/Cycles 32샘플의 실제 원형과 내장 Imagegen 결과를 320/80/48/36px의 Godot 렌더 및 동일 전투 장면에서 비교했다. Blender 초기 기체는 큰 면과 기계적 기능부가 충분하지 않아 단순한 쐐기로 보였다. Imagegen 기체는 장갑 면·쌍포·추진 구조가 메뉴와 작은 전투 크기 양쪽에 남았다. 따라서 주 기체/적/배경/FX 표면에는 Imagegen, 정확한 축과 작은 장비 실루엣에는 Blender, 작은 시스템 정보에는 직접 작성 SVG를 채택했다. Blender 중심의 출발점을 결과에 따라 변경했으며 사용하지 않은 대표 Blender 기체는 게임 패키지에 넣지 않았다.

증거: `art/production-comparison.png`, `art/combat-comparison-blender.png`, `art/combat-comparison-imagegen.png`. 전투 비교는 별도 QA 사본에서 기체 PNG 한 개만 바꿔 같은 카메라·적·HUD를 렌더한 것이다. 원본 게임 자산을 임시 교체하지 않았다.

Web 최대 밀도 첫 결과는 p95 45.3~46.2ms로 불합격이었다. 모델 p95 약 1.9ms, GDScript draw p95 약 6ms, 드로콜 2,049개를 확인했다. 회전 스프라이트의 변환 상태 변경을 줄이고, 탄마다 따로 그리던 외곽 호/안티앨리어싱 원을 공통 탄체 텍스처로 바꿨다. 탄의 밝은 핵 반경은 실제 판정 반경과 같으며 꼬리는 색별 묶음으로 그린다. 기능을 제거하지 않고 드로콜을 1,061개로 줄였다. 초기 실패·배경/동시 작업에 오염된 재측정·최종 단독 측정을 구분해 보관했다.

## 남은 한계

- Windows Computer Use의 FrameArrived/window 캡처가2회 시간 초과했다. 좌표를 추측해 조작하지 않았으며, 실제 exe 실행/엔진 movie 캡처와 같은 Godot 버전의 입력 하네스로 검증했다. OS 하드웨어 직접 조작을 완료했다고 주장하지 않는다.
- 일부 정상 종료 로그에 기존2 ObjectDB 인스턴스 경고가 남는다. 추가 QA는 스크립트를 두 번 붙여 오디오 객체를 고아로 만들던 문제를 고쳐 오류 없이 종료했다. 진단 실패 로그는 원인 기록으로 남겼다.
- 저사양 실제 장치·Safari/Firefox·사람의 장시간 플레이/미적 수용·실제 오디오 청취는 확인하지 않았다. 자체 시각 평가4/5는 상용 등급 인증이나 사용자 승인이 아니다.
- 공개 GitHub/Pages에는 이번 그래픽 버전을 게시하지 않았다. 기존 공개3.18과 로컬 art-20261012는 서로 다른 실행 파일 세대다.
- 계획 조사 Temp `C:\Users\home\AppData\Local\Temp\orbit-breaker-art-review-20261012`는 과거 자동 승인 검토의 `blocked by policy`로 삭제가 실행되지 않았다. 우회/재시도하지 않았으며 임시 정리 잔여로 명시한다.
