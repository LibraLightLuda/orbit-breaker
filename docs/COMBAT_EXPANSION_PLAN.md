# 전투 확장 구현 계획 — 진화 분기·보스 약점·환경 역이용·최종 작전

작성: 2026-10-14. 상태: **구현·로컬 검증 완료**. 실제 결과는 [구현·검증 보고서](COMBAT_IMPLEMENTATION_REPORT.md)를 따른다. 아래는 구현 전 계획 기록이다.

현재 규칙의 기준은 [SURVIVAL_V3.md](SURVIVAL_V3.md), 배포 결과는 [VALIDATION_V3.md](VALIDATION_V3.md)다. 이 문서의 수치는 구현·플레이 검증을 시작하기 위한 **초기 시험값**이며 현재 게임의 확정 규칙이 아니다.

## 1. 범위와 공통 계약

- 요청한 아이디어 4·5·6·7을 모두 구현 대상으로 삼는다. 순서는 피해 처리 정리 → 보스 약점 → 환경 역이용 → 진화 분기 → 최종 작전이다.
- 기존 기체 3종·전장 3종·진화 조건·파츠와 회복 경제를 기반으로 확장한다. 새 재화·장비 인벤토리·수동 조준 조작은 추가하지 않는다.
- 보스 격파와 300초 생존의 돌파 인정, 돌파 이후 사망해도 성공 기록 유지, 600초 강제 붕괴는 유지한다. 최종 작전 성공은 별도 성취다.
- 돌진 거리·방향·무적·입력, 일반 공격, 저장 프로필 위치, 기존 업적과 기록을 유지한다. 아래에서 명시한 분기 수치와 전투 동작만 달라진다.
- 모든 지속 시간은 전투 시간이다. 일시정지·강화·분기 선택·도감에서는 멈춘다. 관전은 기록된 화면 상태를 복원하며 게임 판정을 다시 실행하지 않는다.
- 적 240·탄/설치물 240·경험치 300·위험 6의 기존 상한을 유지한다. 전투·아이템 난수에서 새로운 연출용 난수를 소비하지 않는다.
- 변경된 전투 결과까지 과거 실행과 같다고 보장하지 않는다. 기존 기록은 보존하고 새 출격 기록에 규칙 식별자와 선택한 분기·최종 작전 결과를 추가한다.

## 2. 아이디어 4 — 기체 전용 진화의 2갈래 분기

### 발동과 선택 흐름

1. 기존 조건으로 고정 성좌·섬광 항적·반격 성채 중 해당 기체의 전용 진화를 얻으면 분기 선택을 예약한다. 진화 조건과 5분 제한은 그대로다.
2. 현재 강화 선택의 확정 처리를 끝내거나 현재 전투 프레임을 마친 안전한 지점에서 분기 2장을 표시한다. 진화 검사 안에서 즉시 화면을 바꾸거나 진행 중인 피해 처리를 중단하지 않는다.
3. 한 출격에 한 번 선택하며 해당 출격 동안 고정한다. 경험치·파츠·강화 횟수는 소비하지 않는다.
4. 사망/600초 종료가 발생했다면 선택 예약을 폐기한다. 살아 있다면 분기 선택 후 미션 보상 강화와 일반 레벨업 선택을 기존 순서로 이어간다.
5. 화면 회전과 도감 복귀 시 선택 대기를 보존한다. 선택 화면에서 시간이 흐르거나 회복·방벽·스킬이 충전되지 않는다.

### 초기 시험값

아래 피해 배율은 현재 해당 무기의 피해식에 적용하는 분기 배율이다. 모든 무기의 공통 화력에 곱하지 않는다.

스트라이커는 기존 조준 증폭과 진화 숙련을 계속 공유한다. 집중 포대 재배치는 자신의 이전 포대만 교체하며 다른 탄환을 지우지 않는다. 방어 진지는 설치 시 만료된 포대부터 정리한다. 전체 탄 상한에서는 새 생성이 대기한다.

스카우트 항적은 최대 6개와 기존 타격 주기를 유지한다. 새 경로가 생성될 때 6개를 넘으면 가장 오래된 항적부터 교체한다. 같은 돌진의 동일 적 직접 타격 1회 규칙을 유지한다. 돌진 거리·무적·재사용 시간은 분기에서 바꾸지 않는다.

배스천의 방벽 용량, 피격당 1스택 소모, 피해 감소율, 반격 범위와 적탄 제거 범위는 그대로다. 분기 선택 시 보유 스택은 보존하고 충전 중인 시간만 남은 비율에 맞춰 환산한다. 선택만으로 스택을 추가 지급하지 않는다.

### 표현과 완료 기준

- 가로·세로 모두 스크롤 없는 2장 카드에 핵심 장점·대가와 짧은 동작 예시를 표시한다. 전투 중에는 기체 특성 표시 옆 작은 분기 아이콘만 남긴다.
- 포대의 집중 조준선/영역 고리, 항적의 길이와 밝기, 반격의 무게감과 충전 박자로 분기를 구분한다. 색만으로 구분하지 않는다.
- 3기체 × 2분기의 수치·상한·선택 1회·일시정지·재출격 초기화를 검사한다. 전용 진화가 없는 기체나 잘못된 분기 ID는 모델에서 거부한다.
- 한 분기가 단일 보스·포위전·이동전 모두에서 우세하면 수치를 재조정한다. 평균 피해량만으로 합격시키지 않는다.

## 3. 아이디어 5 — 보스 약점 노출 주기

### 전투 규칙

- 기본 지휘체와 추격 지휘체에 적용한다. 현재 전장별 탄막과 체력 절반의 격앙 단계는 유지한다.
- 기존 예고 후 실제 탄막 발사를 3번 마치면 코어가 열린다. 1단계는 2.25초, 격앙 단계는 1.8초다.
- 노출 중 받는 플레이어 무기 피해는 ×1.50, 이동 속도는 통상 전투 속도의 40%다. 새 공격의 예고와 발사를 멈추고 이미 발사된 탄은 유지한다.
- 노출이 끝나면 발사 횟수를 초기화하고 다음 공격 대기를 시작한다. 닫힌 상태의 피해는 기존 ×1.00이며 별도 장갑 감산을 추가하지 않는다.
- 체력 절반 전환이 노출 중 발생해도 현재 노출을 끊지 않는다. 다음 공격 주기부터 격앙 수치를 사용한다.
- 기절 중에는 공격 진행이 멈추지만 열린 약점의 남은 전투 시간은 감소한다. 기절 반복으로 약점 시간을 무한히 늘리지 않는다.
- 탄/위험 수 상한 때문에 공격이 실행되지 않았다면 횟수를 올리지 않는다. 기존 사격 함수가 실제 탄 또는 전장별 공격 위험을 하나 이상 생성했는지를 반환하도록 보완한다.

### 피해·표현·검증

- 피해 배율은 공통 적 명중 처리에서 한 번 적용한다. 자동포·위성·미사일·번개·충격파·돌진·포대·항적·반격·지뢰·도끼 등 모든 기존 적 피해 경로를 대조한다.
- 환경 자체 피해에는 약점 배율을 곱하지 않는다. 환경 취약 상태와 동시에 있을 때는 큰 취약 배율 하나만 사용한다. 예: 약점 ×1.50 + 용광로 취약 ×1.20 → 최종 취약 ×1.50.
- 코어 개방 모양, 테두리 수축 타이머, 짧은 개방음으로 기회를 알린다. 효과 줄이기에서도 열린 모양과 타이머는 남긴다.
- 발사 3회와 노출 경계 시각, 격앙 중 전환, 기절, 보스 2기의 독립 주기, 탄 상한, 사망 직전 타격, 정지/재개를 검사한다.
- 첫 시험에서는 보스 HP를 함께 올리지 않는다. 공격 기회를 추가한 효과를 먼저 평가하고 필요할 때만 재조정한다.

## 4. 아이디어 6 — 환경 위험 역이용

### 초기 적용 범위

| 위험 | 적에게 적용할 효과 | 제한 |
| --- | --- | --- |
| 번개 회랑의 전기 통로 | 일반 적 최대 HP의 20%, 정예 5%, 보스 2% 피해 | 같은 통로의 한 번 발동에서 같은 적에게 1회. HP는 최소 1 유지. |
| 잔해 용광로의 예고 폭발 | 4초간 플레이어에게 받는 피해 증가: 일반/정예 ×1.20, 보스 ×1.10 | 중복 피해 증가는 없고 재노출은 남은 시간을 4초로 갱신. |
| 공통 블랙홀 | 현재의 적·탄환 흡인을 그대로 활용 | 신규 피해·무한 압축 보너스 없음. 기존 끌림과 설치 무기 조합을 시각적으로 읽기 쉽게 표시. |

유성우·태양 플레어·행성 방어에는 이번 단계에서 적 대상 효과를 추가하지 않는다. 범위를 전기 통로와 용광로 폭발 두 판정으로 제한한다.

### 판정과 경제

- 예고 중에는 적에게 효과가 없다. 활성화된 실제 도형과 적의 충돌 반경이 겹칠 때만 적용한다. 도형은 현재 플레이어 위험 판정의 사각형/원 데이터를 공유한다.
- 전장 자체가 생성한 통로/폭발만 대상으로 한다. 같은 도형을 쓰는 적의 포격과 보스 공격은 생성 출처로 구분하여 아군 적을 약화시키지 않는다.
- 통로마다 영향을 받은 전투 개체 ID를 보관한다. 한 활성 기간에 늦게 진입한 적도 1회 적용하며, 벗어났다 다시 들어와도 반복 적용하지 않는다. 집합은 위험 종료 시 폐기하고 최대 적 수로 제한한다.
- 환경 직접 피해는 HP를 1 아래로 내리지 않아 점수·경험치·오버드라이브·처치 콤보를 독립적으로 발생시키지 않는다. 이후 플레이어가 처치하면 현재 보상을 한 번 받는다.
- 환경 취약은 기존 약점 배율과 최댓값으로 결합한다. 기체 화력·오버드라이브·무기별 분기는 평소대로 적용한다.
- 최종 작전의 보호 장치는 환경 직접 피해와 취약 효과를 받지 않는다. 보호 장치가 모두 파괴된 지휘 핵은 일반 보스와 같은 환경 규칙을 따른다.
- 기존 플레이어 위험 피해·예고 길이·적/위험 상한·블랙홀 이동 계산은 유지한다. 환경 판정을 위해 매 프레임 전체 적×모든 무기 조합을 추가하지 않는다.

### 표현과 완료 기준

- 감전은 적의 짧은 전기 섬광, 용광로 취약은 금 간 장갑 기호와 만료 표시로 구분한다. 전투 중 긴 설명을 추가하지 않는다.
- 예고 중 무효, 도형 가장자리, 출입 반복, 위험 2개 중첩, HP 1, 기절/무적 차이, 보스 약점 중첩, 보상 중복 없음과 일시정지를 검사한다.
- 적을 유도한 행동과 효과의 원인을 실제 화면에서 구분할 수 있어야 한다. 최대 적/탄/위험 조건에서 프레임 비용을 기존 본과 비교한다.

## 5. 아이디어 7 — 마지막 1분의 선택형 최종 작전

### 시간과 선택

자격은 08:50 제안 시점에 확정한다. 이후 처음 돌파에 성공한 판에는 최종 작전을 갑자기 끼워 넣지 않는다. 09:00 전에 사망하면 시작되지 않은 작전으로 기록한다.

### 대상과 전투

- 09:00에 살아 있는 지휘체 중 플레이어에게 가장 가까운 한 기를 최종 지휘체로 지정한다. 없으면 기존 보스 출현 경계와 접근 규칙으로 1기를 생성한다. 기존 적을 순간 이동시키지 않는다.
- 기존 대상의 현재 HP·최대 HP·격앙 단계·이동을 보존한다. 살아 있는 보스가 없는 경우에는 기존 추격 보스 생성 경로를 재사용한다.
- 보스에 보호 장치 2개를 붙인다. 각각 지정 시점 보스 최대 HP의 8%, 보스 중심 양옆 70px, 충돌 반경 18px를 초기값으로 한다. 배치 축은 지정 순간 보스 진행 방향의 수직축으로 고정하며, 이후 몸체와 함께 평행 이동한다. 장치 HP와 위치는 보스의 부속 상태이며 적 목록의 추가 개체로 넣지 않는다.
- 두 장치가 모두 파괴되기 전에는 지휘 핵에 피해가 들어가지 않는다. 자동 표적 무기는 살아 있는 보호 장치의 실제 좌표를 겨냥한다. 새 수동 조준 입력을 요구하지 않는다.
- 직선 탄은 이동 구간에서 가장 먼저 충돌한 유효 부위를 맞힌다. 범위 공격은 범위 안의 살아 있는 장치 중 폭발 중심에 가까운 하나를 맞히며, 지휘 핵은 장치 파괴 후 타격한다. 동일 공격의 동일 보스 대상 피해 주기에 부위를 중복 계산하지 않는다.
- 연쇄 공격은 같은 보스의 두 장치를 별도 적으로 연속 타격하지 않는다. 관통·돌진·위성의 현재 동일 대상 재타격 제한도 보스 단위로 유지한다.
- 표적 탐색과 공간 격자의 후보 범위에는 중심에서 88px까지의 장치를 포함하되, 플레이어와 보스의 몸체 접촉 반경은 키우지 않는다. 보호 중인 핵은 유효 공격 표적에서 제외한다.
- 마지막 보호 장치가 파괴되면 지휘 핵을 3초간 노출한다. 이후 아이디어 5의 3회 발사 주기를 사용하되 최종 지휘체의 노출은 각 3초로 한다. 취약 배율은 동일 ×1.50이다.
- 보호 장치가 남아 있을 때에는 보스의 코어 노출 보너스를 장치에 적용하지 않는다. 노출 기회를 잘못 안내하지 않도록 코어 개방 표시는 장치 파괴 이후부터 사용한다.

### 혼잡과 보상

- 일반 적·정예·추격 지휘체·공통 이벤트·전장 위험의 기존 일정과 상한을 유지한다. 최종 작전을 선택하기만 하고 목표를 무시해도 추격 압박이 줄어드는 우회 이득을 만들지 않는다. 최종 작전 전용 탄막/재해는 별도로 추가하지 않는다.
- 보스는 최대 2기, 적 목록은 최대 240기를 유지한다. 부속 장치의 두 충돌 도형은 성능 검사에 포함한다.
- 보호 장치는 별도 처치 수·경험치·보급·콤보를 지급하지 않는다. 핵 처치에 기존 보스 보상을 한 번만 지급하고, 추가 보상은 최종 작전 훈장과 결과 기록이다. 새로운 회복이나 점수 배율은 추가하지 않는다.
- 훈장은 기존 업적 체계에 성공 1회 조건으로 1종 추가하며 업적 점수는 100점을 초기값으로 한다. 전투 점수와 구분한다.
- 600초 미만에 확정된 핵 처치만 작전 성공이다. 바로 다음 프레임이 600초여도 이미 확정된 성공은 유지한다. HP 0/종료 상태에서 새 피해나 성공을 처리하지 않는다.
- 기존 590초 붕괴 예고와 마지막 카운트다운을 재사용한다. 작전 알림이 같은 시각의 경고음을 중복 재생하지 않는다.

### 표현과 완료 기준

- 기존 미션 영역에 보호 장치 2개의 기호 → 핵 HP → 성공 상태를 차례로 표시한다. 보스 방향 표시는 현재 가장자리 안내를 재사용한다.
- 선택 버튼은 기존 게임 입력으로 전파되지 않게 처리하고 터치 영역을 최소 44px로 확보한다. 작은 가로·세로 화면에서 HUD/스킬 입력과 겹치지 않는지 실제 렌더로 확인한다.
- 대상 보스 유무, 보스 2기·최대 적 수, 자동 표적과 모든 무기 유형, 부속 장치 중복 피격, 미션 대체, 무응답 기본값, 실패 페널티 없음, 일시정지, 599.99/600초 경계와 성공 후 사망을 검사한다.
- 최종 작전은 장치를 무시하고 무작위로 버티는 것과 다른 행동을 유도해야 한다. 장치 파괴에 걸리는 시간과 남은 핵 공격 시간을 기체·분기별로 비교해 HP를 조정한다.

### 먼저 해결할 공통 처리

- 현재 적 피해는 공통 명중 함수에 모이지만 처치 정산은 적 갱신에서 이뤄진다. 탄/위험의 뒤늦은 피해가 다음 프레임 정산으로 밀릴 수 있으므로 **프레임 끝의 사망 확정 처리**를 공유해 점수·보급·최종 성공을 같은 프레임에 한 번만 확정한다.
- 피해 출처는 플레이어 무기/환경을 구분할 최소 인자만 추가한다. 기존 무기 호출은 기본값을 사용하고 환경 경로만 명시한다. 범용 전투 이벤트 프레임워크로 재작성하지 않는다.
- 부위 표적은 최종 보스에만 적용한다. 기존 무기 표적 탐색과 충돌 경로를 모두 조사하여 닫힌 핵을 계속 공격하거나 위성/돌진만 통하지 않는 예외를 없앤다.
- 현재 강화 화면은 3택과 레벨업 상태를 전제로 하므로 분기 선택을 일반 강화 횟수로 위장하지 않는다. 분기용 상태/확정 처리를 얇게 추가하고 카드 배치·입력·정지 동작을 재사용한다.

### 저장·고스트 계약

- 기존 저장에 새 필드가 없으면 분기 없음·최종 작전 미선택·기존 규칙으로 읽는다. 과거 성공이나 시간을 보고 새 훈장을 추정 수여하지 않는다. 기존 기록/백업/고스트를 삭제하거나 초기화하지 않는다.
- 새로운 ID는 허용 목록, 숫자는 유한값·범위·배열 길이를 검사한다. 손상된 추가 필드는 기존 정상 기록까지 덮어쓰지 않는 현재 검증/복구 방식을 따른다.
- 고스트의 기존 개체 행은 고정 길이 검증이 있으므로 끝에 열을 무작정 붙이지 않는다. 기존 world 안에 선택적인 combat 확장과 자체 스키마 번호를 추가하고, 기존 replay 개체 ID에 새 표시 상태를 연결한다.
- 확장에는 분기 ID, 보스 노출 잔여 시간, 적 취약 상태, 최종 장치 좌표/HP, 작전 단계/성공 시각 등 재생에 필요한 상태만 기록한다. 환경 중복 판정 집합처럼 관전에 필요 없는 실행 내부 자료는 저장하지 않는다.
- 과거 고스트의 확장이 없으면 새 효과는 없는 것으로 복원한다. 되감기 시 직전 프레임의 새 상태가 남지 않게 반드시 초기화한다. 장치 파괴·성공 같은 불연속 상태는 미래 프레임에서 앞당겨 보간하지 않는다.
- 파일 크기/프레임/개체 상한과 비동기 저장을 유지한다. 기존 세계 스냅샷·구형 경로 고스트·신규 고스트를 모두 열고 임의 시각 seek와 왕복 검증을 한다.

새 기능의 모델 검사는 한 전투 확장 검사 파일로 시작하고, 기존 test_survival / test_events / test_feedback_v318 / test_replay_world / test_progression / test_balance / 화면·오디오 검사에는 관련 회귀만 추가한다. 실제 함수와 배열을 그대로 따라 쓰는 테스트 대신 경계 시각·중복·호환·선택 조합을 검증한다.

밸런스 평가는 3기체 × 2분기 × 3전장의 표준 난도 조합을 기본으로 하고, 여유롭게/대붕괴에서 약점·환경·최종 작전의 극단값을 확인한다. 무피격 합성 검사는 회복 계약용이며 사람의 재미 평가를 대체하지 않는다. 사람 플레이에서는 분기 선택 이유, 약점 인지, 환경 유도 성공, 최종 작전의 성공/실패 원인이 읽히는지를 확인한다.

성능은 동일 환경의 현재 검증본을 기준으로 모델+렌더+HUD+고스트를 포함해 비교한다. 최대 밀도에서 p95 프레임 비용이 반복 측정 기준 10% 넘게 악화되면 원인을 해결하고 다시 검증한다. 기존 하드웨어 결과를 실물 휴대폰·저사양 보증으로 확대하지 않는다.

## 8. 구현 이후 배포

기존 최신 실행 파일·체크섬·안내·대응 검증 자료를 보존한 뒤 build/candidate와 artifacts/candidate에서 검사한다. 필수 회귀·실제 렌더·Windows/Web 내보내기·최종 실행·체크섬이 성공한 후에만 current를 교체한다. 성공 후 이전 배포/증거/임시 백업을 정리하여 최신 한 세대만 남기고, 차단된 정리는 남은 경로와 정확한 이유를 기록한다. 소스·과거 계획·플레이어 저장은 정리 대상이 아니다. 공개 게시 여부는 실제 구현 작업의 배포 범위에서 별도로 정한다.

## 9. 첫 구현에서 줄인 범위

4개 요청은 모두 포함하되, 전용 진화 3종의 6분기·보스 전체 코어 약점·환경 상호작용 2종·최종 작전 1종으로 제한한다. 모든 12진화의 분기, 방향별 일반 보스 장갑, 모든 재해의 아군 피해, 추가 엔딩/새 모드/새 재화는 넣지 않는다. 이 범위로 핵심 경험을 검증한 뒤 추가 필요성을 판단한다.
