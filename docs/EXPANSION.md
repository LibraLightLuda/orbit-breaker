# ORBIT BREAKER 2.0 — 확장 범위

## 플레이 목표

5분 생존의 짧은 길이는 유지하면서 출격 전 선택과 전투 중 성장 경로를 늘립니다. 다른 함선·구역과 무기 조합으로 다시 플레이할 이유를 만들고, 정예전과 오버드라이브로 한 판 안의 강약을 구분합니다.

## 2.0 콘텐츠

| 항목 | 범위 |
| --- | --- |
| 함선 | 균형형 스트라이커, 기동형 스카우트, 방어형 배스천. 모두 처음부터 선택 가능 |
| 구역 | 외곽 고리, 번개 회랑, 잔해 용광로. 각기 다른 보스 탄막과 구역 위험 |
| 난이도 | 표준·여유롭게. 함선·구역과 함께 18가지 출격 조합 |
| 신규 무기 | 미사일, 연쇄 번개, 충격파 |
| 무기 진화 | 지정된 강화 조합을 달성하면 자동으로 발동하는 진화 3종 |
| 전투 흐름 | 90·180초 정예전, 240초 최종 보스, 300초 생존과 보스 처치 시 승리 |
| 오버드라이브 | 처치로 충전하고 100에서 E로 발동하는 능동형 전투 수단 |
| 기록 | 함선·구역·난이도별 기록, 최근 8회 출격, 영구 도전 메달 6종 |
| 배포 | `build/v2/OrbitBreaker.exe`. 초기 MVP 실행 파일과 분리 |

게임 규칙의 값과 진화 조건은 `scripts/game_content.gd`와 `scripts/run_model.gd`를 기준으로 합니다. 기록은 로컬에 저장하며, 기존 저장 데이터가 있는 사용자의 기록을 보존하는 방향으로 확장합니다.

외곽 고리는 지형 위험 없이 전투에 집중합니다. 번개 회랑에서는 전기 통로, 잔해 용광로에서는 원형 폭발을 예고하는 표시 밖으로 이동해야 합니다. 함선은 체력·속도·대시·기본 화력·시작 위성 수가 달라 같은 구역에서도 다른 이동 판단을 요구합니다.

| 자동 진화 | 필요한 강화 조합 | 변화 |
| --- | --- | --- |
| 태양 고리 | `orbit` 3회 + `power` 2회 | 위성 피해·접촉 범위·타격 속도 증가 |
| 연쇄 폭풍 | `chain` 3회 + `rapid` 2회 | 번개 연결 수와 피해 증가 |
| 유성 세례 | `missile` 3회 + `dash` 2회 | 유도탄 3발 동시 발사와 폭발 범위 증가 |

## 확인 기준

- 함선 3종과 구역 3곳을 선택하고 각 조합으로 출격할 수 있습니다.
- 신규 무기 3종이 공격하며, 진화는 필요한 조합을 갖춘 뒤에만 발동합니다.
- 정예전, 구역 위험, 오버드라이브가 기존 이동·대시·성장과 함께 동작합니다.
- 재시작은 이전 전투 상태를 초기화하고 기록·메달은 다음 실행에도 유지합니다.
- 모델·확장 기능·저장/사운드·UI 검사의 통과 집계를 모두 확인한 뒤 내보냅니다.
- 자동 조종 검사는 고정 시드 7에서 함선 3종 × 구역 3곳 × 난이도 2종의 18조합을 실행합니다. 체력·시간을 변경하지 않고 이동·대시·제시된 강화 선택·충전된 오버드라이브만 사용합니다.
- 각 자동 조종 출격은 유한한 좌표·체력·시간을 유지하고 승리 또는 패배로 종료해야 합니다. 여유롭게 난이도는 각 구역에서 최소 한 함선의 승리를 확인합니다.

자동 조종 결과는 반복 가능한 규칙·밸런스 관찰입니다. 사람의 손으로 익히는 난도, 재미, 장시간 플레이 안정성에 대한 보장은 아닙니다. 실제 통과 수, 실행 파일 해시와 화면 검증은 별도의 검증 문서에 기록합니다.

## 이번 범위에 포함하지 않는 것

고급 그래픽 리소스 제작, 추가 플랫폼, 온라인 계정·순위표, 멀티플레이, 유료 상품은 추가하지 않습니다. 반복 플레이의 차이는 콘텐츠 조합과 전투 규칙에서 만듭니다.
