# MVP 검증 기록

검증일: 2026-10-10 (한국 시간). 엔진: Godot 4.7.1 stable.official.a13da4feb.

## 소스와 게임 흐름

- `tests/test_model.gd`: 전투 모델 35/35 검사 통과. 이동 경계, 대시와 무적, 경험치, 강화 효과, 반복 레벨업, 재시작, 보스/승리 조건, 객체 수 제한.
- `tests/test_support.gd`: 저장/오디오 49개 검사, 실패 0. 잘못된 저장 데이터, 백업 복구, 설정 검증, 생성한 PCM 데이터, 음성 수 제한, 음소거 및 음악 수명.
- `tests/test_ui.gd`: 화면 흐름 16/16 검사 통과. 실제 입력 전달, 일시정지, 강화 선택 중 시간 정지, 재시작, 결과의 중복 저장 방지, 승리 기록.
- OpenGL로 UI를 렌더링한 캡처 검사 24/24 통과. 메뉴, 도움말, 전투, 일시정지, 강화 선택, 보스, 패배/승리 화면의 캡처를 `artifacts/`에 저장.
- 화면 캡처는 배치 확인을 위한 결정적 시나리오이며 사람의 플레이 기록이 아니다.

## 5분 자동 플레이

`tests/test_balance.gd`는 이동, 대시, 제시된 강화 선택만 입력한다. 진행 시간이나 체력 변경 없이 전체 전투를 시뮬레이션한다. 원본 출력은 `tests/balance_results.txt`에 있다.

| 난이도 | 난수 시드 | 결과 | 종료 시각 | 처치 |
| --- | ---: | --- | ---: | ---: |
| 표준 | 7 | 승리 | 300.0초 | 564 |
| 표준 | 42 | 보스 전투 중 패배 | 257.4초 | 404 |
| 표준 | 2026 | 승리 | 300.0초 | 567 |
| 여유롭게 | 7 | 승리 | 300.0초 | 567 |
| 여유롭게 | 42 | 승리 | 300.0초 | 561 |

최종 보스 체력은 3,600. 표본의 강한 조합에서는 보스 전투가 약 15~17초 지속됐다. 여섯 사례는 끝까지 진행 가능한지 확인하는 표본이며 전체 사용자 승률의 추정값은 아니다.

## Windows 최종 실행 파일

- `build/OrbitBreaker.exe`: Windows x86_64 Release, PCK 내장. Godot 별도 설치 없이 실행하는 단일 파일.
- 파일 크기: 109,263,184 bytes.
- SHA-256: `C60473D77CFAE1472EE9DE79B5B998C3CA824F35A2A827275E9A6DCE6E369ED3`.
- 최종 빌드에서 모델 35개 + 저장/오디오 49개 + UI 16개, 총 100개 기본 검사 재통과.
- 개발용 `addons/`, 테스트, 문서, 캡처는 내보내기에서 제외. 개발용 자동 로드 항목 없음.
- 최종 EXE를 직접 실행해 게임 창과 응답 상태를 확인했다. 별도 EXE 렌더링 검사도 120프레임 뒤 종료 코드 0으로 끝났고 오류 로그가 없었다. NVIDIA GeForce RTX 4070 Ti, OpenGL 3.3 Compatibility에서 확인.
- 소스 UI 캡처 검사는 1280×720과 960×540에서 각각 24/24 통과했다. 캡처 폴더에는 마지막 960×540 검증 결과가 있다.
- 데스크톱 검증 도구는 `FrameArrived timed out` 및 `failed to activate captured window` 오류로 최종 EXE 화면 캡처/직접 마우스·키보드 조작을 검증하지 못했다. 소스 UI의 입력 전달 검사는 통과했지만 이를 수동 EXE 조작 검증으로 간주하지 않는다.
- Release 템플릿은 외부 `--script` 검사 실행을 수행하지 않아 그 시도를 통과로 계산하지 않았다. 해당 검사 프로세스는 종료했고, 위 EXE 렌더링 검사는 별도로 실행했다.

## 제한

사람 대상 재미/인기 검증, 장기간 플레이, 저사양 PC, 다른 운영체제, 실제 스피커로 믹스 품질 평가는 수행하지 않았다. 게임은 인터넷 연결 없이 동작하며 테스트 저장은 실제 플레이 기록과 다른 경로를 사용한다.
