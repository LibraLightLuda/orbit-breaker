# ORBIT BREAKER — MVP 범위

## 플레이 약속

**이동과 대시만 익히면 바로 즐길 수 있고, 5분 안에 하나의 성장 조합을 완성하는 1인 생존 액션.** 자동 공격이 조작 부담을 줄이고, 적 사이를 통과하는 판단과 강화 선택이 반복 플레이의 차이를 만듭니다. 인기를 보장하기보다 짧은 세션, 즉각적인 피드백, 재도전하기 쉬운 구조를 검증합니다.

## 한 판의 흐름

1. 타이틀에서 표준 또는 여유롭게 난이도를 선택합니다.
2. 회전 무기와 자동 사격으로 적을 처치하고 경험치를 수집합니다.
3. 레벨업마다 무작위로 제시되는 강화 3개 중 1개를 고릅니다.
4. 시간이 흐르면 적의 수와 압박이 증가합니다. 대시로 포위를 벗어납니다.
5. 240초에 최종 보스가 등장합니다. 300초 이상 생존하고 보스를 처치하면 승리합니다.
6. 승패, 생존 시간과 기록을 확인하고 즉시 재도전합니다.

## 구현 범위

| 항목 | MVP 기준 |
| --- | --- |
| 플랫폼 | Godot 4.7.1, Windows x86_64, Compatibility 렌더러 |
| 전장 | 한 화면 중심의 단일 생존 전장 |
| 입력 | WASD·방향키 이동, Space 대시, 자동 공격 |
| 성장 | 8~10종 강화 풀, 레벨업마다 3개 중 1개 선택 |
| 적과 종료 | 일반 적의 압박 증가, 최종 보스, 사망·승리·재시작 |
| 난이도 | 표준과 부담을 줄인 여유롭게 |
| 편의 | 일시정지, 음소거, 전체 화면, 키보드 강화 선택 |
| 저장 | 로컬 최고 기록과 설정 |
| 표현 | 직접 그리는 기하 도형, 색상 대비, 간단한 효과·절차적 효과음 |
| 배포 | 게임 데이터를 포함한 단일 Windows 실행 파일 |

## 완료 확인 기준

- 프로젝트가 오류 없이 로드되고 새 게임을 시작할 수 있습니다.
- 이동·대시·자동 공격·경험치·강화 선택이 한 판에서 이어집니다.
- 체력이 0이 되면 패배하며 재시작 시 이전 판 상태가 남지 않습니다.
- 보스 출현과 승리 조건을 모델 검사로 확인합니다.
- 일시정지와 강화 선택 중에는 전투가 진행되지 않습니다.
- 최고 기록과 설정을 다음 실행에서 다시 읽을 수 있습니다.
- Windows Release 실행 파일을 생성하고 실제 창에서 시작 화면과 플레이 화면을 확인합니다.

각 항목은 검증 목표입니다. 자동 검사 통과, 빌드 성공, 실제 화면 확인, 사람이 느끼는 재미는 서로 다른 확인 단계로 기록합니다.

## 이번 버전에서 미루는 것

고해상도 그래픽 제작, 여러 스테이지, 영구 성장 재화, 스토리, 온라인 순위표, 멀티플레이, 결제, 모바일 배포는 만들지 않습니다. 먼저 한 판의 전투와 선택이 반복할 만한지 확인합니다. 밸런스와 재미는 실제 플레이 피드백에 따라 조정할 수 있습니다.
