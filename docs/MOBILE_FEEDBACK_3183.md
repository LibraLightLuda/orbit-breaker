# 3.18.3 모바일 화면·조작 피드백 반영

2026-10-13. 게임 규칙은 `SURVIVAL_V3.md`, 최종 배포 판정과 체크섬은 `VALIDATION_V3.md` 및 `artifacts/current/verification.json`을 따른다.

1. **출격 준비 떨림:** 같은 화면에서 기체·전장·난이도를 바꿀 때 진입 이동/페이드 애니메이션을 다시 실행하지 않는다. 크기 변경도 진입 애니메이션을 반복하지 않는다. 작은 화면의 선택 버튼은 위치와 크기를 유지한다.
2. **메인·출격 준비:** 가로/세로의 실제 화면 크기를 사용한다. 메인 메뉴의 모든 버튼, 기체 3종, 전장 3종, 난이도 4종, 이름 입력과 출격 버튼을 한 화면에 배치한다. 중복 대형 미리보기와 장식은 작은 화면에서 생략한다. 기체/전장 설명은 핵심 효과를 유지한 짧은 표현을 사용한다.
3. **모바일 스킬:** 드래그로 이동한다. 0.3초 이상 누르고 실제 화면에서 48px 이상 끌었다 놓으면 시작점→끝점 벡터로 돌진한다. 짧은 드래그는 이동만 한다. 단일 탭은 스킬을 쓰지 않으며, 0.24초 내 52px 이내 두 번 탭은 오버드라이브만 발동한다. 취소/화면 전환은 입력을 지운다. 기존 즉시 스킬 버튼, WASD·Space·E와 데스크톱 마우스는 유지한다.
4. **강화 선택:** 세로는 세 카드의 세로 배치, 가로는 세 카드의 가로 배치를 사용한다. 카드 전체가 선택 영역이다. 이름·현재/다음 단계·효과·변화량·진화 조건을 한 화면에 표시한다. 긴 효과 설명의 실제 높이에 맞춰 변화량과 조건 위치를 계산한다. 모바일의 페이지 스크롤과 조건 스크롤은 사용하지 않는다. 이후 선택 화면도 스크롤 없이 비교 가능한 배치를 우선한다. 긴 도감/기록 목록은 기존 구조를 유지한다.
5. **화면 밖 보급·파츠:** 공통 코드로 모든 화면 밖 대상을 가장자리에 표시한다. 화살표, 대상 아이콘/등급 색, 거리, 남은 수명과 잠금을 표시한다. 중앙의 최근접 중복 안내는 제거했다. 모바일 상단 HUD·하단 스킬 영역을 피하고 실제 화면 픽셀 크기로 표시한다. 가까운 안내 문구는 위치를 옮기고 연결선으로 실제 방향 표시를 유지한다.

## 검증 범위

모바일 전용 엔진 검사는 360×606, 360×640, 390×844, 667×341, 667×375, 844×356, 844×390, 1024×768에서 수행한다. 메인/출격 준비, 전체 강화 계열의 설명·조건·경계와 카드 안 텍스트, 긴 설명/변화량/조건의 겹침과 숨은 넘침, 선택 후 위치 유지, 네 방향과 세 픽셀 배율의 돌진, 취소, 가장자리 안내를 확인한다. 별도의 실제 viewport 터치 검사로 이동·돌진·두 번 탭·UI 입력 차단을 검사한다. Web에서는 기존 세로 회전 권장 안내를 숨겨 첫 기체를 가리지 않게 한다.

전체 게임 회귀, 16개 렌더 사례, 아트 검사, Windows/Web 내보내기, 최종 실행 파일 실행과 실제 플레이어 프로필 불변, Chromium의 후보/공개 화면 확인을 각각 기록한다. 최종 통과 수와 공개 상태는 검증 명세를 확인한다. 물리 휴대폰, Safari, 저사양 장치 성능과 장시간 사람 플레이는 확인하지 않았다.

기체/전장 데이터, 전투 모델, 저장/고스트 형식은 변경하지 않았다. 새 정상본이 필수 검사를 통과하기 전에는 기존 정상본을 보존하며, 교체 후 이전 배포 세대와 이번 임시 staging을 정리한다. 이전에 정책으로 차단된 임시 경로는 재시도하지 않고 보관 상태에 남긴다.
