요청: 미션 표시가 왼쪽 아래 전투를 덜 가리도록 하고 5분 이후 강적 빈도와 강화를 높인다. 기존 미커밋 작업 위에 수정하며 저장/도감/미션 보상/리플레이 형식은 유지한다.

- 완료: 미션 패널 392×138 → 564×56 (면적 약42% 감소), 상단478 →568. 전투 중 핵심 정보, ESC 상세 설명. 성공 진행 막대 실제 픽셀 검사 위치를 함께 변경했다.
- 완료: 300초부터 정예35→20초 주기, 돌격/포격 교대, 매분 체력 강화, 동시2기 제한.
- 완료: 330초부터 추격 보스50→35초 주기, 첫 보스 처치에 의존하지 않음, 동시2기 제한, 격파로 시간 지연 없음. 기존 파동별 강화/전장 패턴/경보/25초 붕괴 완화 보상 유지.
- 완료: 후반 생성 적 분당 속도+4%, 접촉/탄환 피해+8%, 탄속+2.5%. 기존 체력 증가 유지. 강적 외곽 접근만 가속하고 근접/영역 진입 후 정상 속도.
