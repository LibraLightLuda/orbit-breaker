## 저장 호환성

새 버전은 `user://records_v2.json`을 사용한다. 기존 MVP의 `records.json`은 확장판 저장과 백업이 모두 없을 때만 읽는다. 이후의 저장은 v2 파일에만 수행한다. 이전 기록의 점수·승리·설정은 이어받고, 과거 기록으로 확인 가능한 훈장은 이관하되 새 훈장 알림으로 반복하지 않는다. 검사 파일은 고유한 별도 경로를 사용하며 실제 플레이어 기록을 수정하지 않았다.

## 확인하지 않은 범위

실제 사람이 Windows EXE를 직접 조작해 5분을 플레이한 검증, 장기간 사용, 저사양 PC·다른 운영체제, 실제 스피커의 음질 평가는 수행하지 않았다. 자동 조종의 승률은 사람의 승률이나 재미·인기를 나타내지 않는다. 입력 검사는 Godot 입력 이벤트 전달과 화면 흐름 검사이며 운영체제의 물리 키 입력 검사와 구분한다.
