# ORBIT BREAKER 3.18 — 전투 다양화·웹 배포 검증

2026-10-12. Windows: `build/current/OrbitBreaker.exe`. Web: `build/current/web/` 및 `web/`. 대응 자료: `artifacts/current/`. GitHub 공개 웹 주소: https://libralightluda.github.io/orbit-breaker/ . 공개 배포 결과는 아래 게시 상태와 `github-publication.json`을 따른다.

## 적용 범위

획득 알림 배경6%/글자60%, 보급35초·파츠45초 수명과10초 경고/소멸 알림, 외곽 경험치 흐름5px/초를 적용했다. 기존6종에 기체 전용3종과 공통3종 진화를 더했다. 경험치·점수 증폭, 자연붕괴를 포함한 흡수 실드, 돌진 재충전 가속 아이템을 추가했다. 스트라이커 증폭 저점과 속도/선회 감소를 조정했고 기체별 전용 파츠 강화2종씩을 단계 해금한다. 전장별 붕괴·전역 번개·고속 포위를 강화했다. 세부 규칙은 SURVIVAL_V3.md의3.18절을 따른다.

도감은 진화6개씩2페이지, 아이템8개/4개2페이지, 기체 테크트리는 공통 조합과 전용 파츠 페이지다. 버프9개 동시 활성 시2행 배치로 파츠 표시와 분리했다. 실드 잔량·방벽 스택과 타원 궤도/설치물/귀환 도끼도 표시한다.

## 검증 결과

- 자동 검사2,272/2,272: 19개 묶음, 신규 피드백294개 포함. `automated-results.json`과 각 `test-*.log`가 최종 결과다.
- 실제 화면 검사2,504/2,504: 16개 사례,1600×900/960×540 및 기존 다른 비율 확인. `render-results.json`과 해당 이름의 로그가 기준이다. 최종 하단 재배치·알림 그림자 제거는 마지막 feedback318 두 크기 캡처에서 직접 확인했다. 마지막 전장 안내 문구 변경은960×540 사례와 최종 내보내기에 포함했다.
- 36개 기체×전장×난이도 장기 전투가 유한 상태로10분 이내 종료했고, 각 전장에 여유롭게 난이도 돌파 사례가 있다. 이는 자동 조종 검사이며 사람의 밸런스 승인은 아니다.
- Windows/Web Release 내보내기 성공. 최종 Windows 실행 파일180프레임, 종료0, 스크립트 오류 없음. 소스 실제 실행도180프레임 확인했다.
- Chrome 로컬 WASM/PCK 로드, 메뉴→출격 준비→전투·좌클릭 입력을 확인했다. 마지막 후보 PCK를 HTTP200으로 읽어 SHA-256을 비교했다. 공개 사이트는 배포 후 별도 확인한다.
- 기존 기록·도감·설정을 유지한다. 저장의 진화 목록 한도를12개로 늘렸다. 과거13개 scalar/14개 upgrade 고스트 필드를 허용하고 새 방벽/도끼 필드에 기본값을 준다. 잘못된 배열 길이와 누적 상한 초과는 거부한다.
- 아이템별 C/B/A, 증폭1회 적용, 실드 손실 흡수/초과 피해/등급 갱신/600초 종료, 속도·급선회 충전 감소, 기체 전용 해금 순서, 진화 시간/기체 제한, 타원 장단축, 실제 설치 피해/지뢰 소모, 도끼 회수·실패, 설치물 상한·소멸을 검사했다.
- 최대 밀도 기존 성능 fixture:600프레임, 적240·탄240·경험치300. 평균4.866ms/p95 8.446ms/최대18.740ms. 고스트 비동기 polling p95 0.012ms/최대0.477ms. 실제 저사양 장치 성능 보장은 아니다. `performance-status.json`을 따른다.

초기 자동 실행기는 성능 진단의 PERFORMANCE 출력에 SELF-CHECK 형식을 기대해 실패로 분류했다. 실제 프로세스 종료0과5개 assert 성공/오류 없음은 별도 확인하여 성능 결과를 분리했다. 옛 밸런스 수치를 기대하던 검사와 테스트 fixture의 외곽 이탈을 수정했고 모든 최종 묶음은 통과했다. 중간 실패를 최종 성공으로 계산하지 않는다.
