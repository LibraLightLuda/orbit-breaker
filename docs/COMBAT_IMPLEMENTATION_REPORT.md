# Orbit Breaker 3.19 전투 확장 구현·검증 결과

2026-10-14. 최신 로컬 세대 combat-20261014. 계획의 4·5·6·7을 구현하고 Windows/Web 후보 검사 후 최신본으로 교체했다.

## 실제 게임 동작

- **진화 분기:** 전용 진화 이후 한 출격에 한 번, 스트라이커 집중 포대/방어 진지·스카우트 지속 항적/관통 돌격·배스천 중량 반격/순환 방벽 중 해당 기체의 두 전술을 고른다. 강화·파츠를 소비하지 않고 선택 중 전투 시간이 멈춘다. 가로·세로 모두 2장 카드이며 1/2 선택과 TAB 도감 복귀를 지원한다.
- **보스 약점:** 실제 공격 3회 뒤 코어를 일반 단계 2.25초·격앙 1.8초 노출한다. 플레이어 피해 ×1.5·이동 40%·신규 공격 중지이며 기존 탄은 남는다. 두 보스의 주기는 독립이다.
- **환경 역이용:** 전장 번개가 일반/정예/보스 최대 체력의 20/5/2%를 한 발동에 한 번 깎으며 HP 1을 남긴다. 용광로 폭발은 4초간 받는 플레이어 피해를 20/20/10% 높인다. 보스 약점과 취약 배율은 큰 값 하나를 적용한다. 적 포격은 아군 적에게 이 효과를 주지 않는다.
- **최종 작전:** 08:50에 이미 돌파한 판에서 도전/생존을 선택한다. 무응답은 생존이며 키보드 1/2와 클릭·터치를 지원한다. 09:00부터 일반 미션 대신 보호 장치 2개→핵 파괴를 수행한다. 장치당 지정 시점 보스 최대 체력의 8%, 장치 파괴 후 노출 3초다. 기존 추격 압박과 10분 붕괴를 유지한다. 실패해도 돌파 성공을 취소하지 않는다. 핵 처치의 기존 보스 보상과 최초 성공 훈장 100점을 지급한다.

파츠·회복 경제·돌진 거리와 무적·기존 조작을 유지했다. 장치는 보스 부속 상태로 구현하여 적/탄/경험치/위험 상한을 늘리지 않는다. 모든 적 피해 경로에서 부위를 선택하며 직선 탄·범위 공격·연쇄·돌진·위성의 동일 보스 중복 타격 제한을 유지한다.

## 저장·고스트·음향

기존 프로필과 백업·고스트를 보존했다. 새 기록은 전술·최종 작전 결과·규칙 식별자를 추가한다. 과거 기록은 중립 기본값으로 읽고 과거 돌파로 새 훈장을 추정 수여하지 않는다. 고스트는 기존 개체 행을 유지하고 선택적 combat 상태를 추가한다. 신/구 읽기·되감기 상태 초기화·유한값/ID/길이 검사를 확인했다. 새 상황 6종은 기존 준비된 음원의 별칭으로 연결했으며 전투 난수에 영향을 주지 않는다.

## 검증 근거

- 최종 빌드 게이트: 24개 검사 묶음, 110,520개 검사 통과. 묶음별 실제 수치는 artifacts/current/automated-results.json이다. 일부 묶음은 기존 UI/실제 렌더를 포함하므로 전부 순수 모델 검사로 부르지 않는다.
- 새 기능 모델/저장/고스트 검사 **194/194**. 6분기·일시정지·상한·보스 주기·환경 중복/출처·599.99/600초·훈장·손상된 추가 필드와 11개 무기 경로의 보호 장치 판정을 포함한다.
- 새 실제 화면·입력 검사 **472/472**. 1600×900, 960×540, 390×844, 844×390, 320×568, 568×320의 실제 창 크기, 스크롤 없는 카드·문구 겹침·실제 Viewport 클릭·회전·키보드 선택·도감·장치·핵·결과 화면을 확인했다. PNG는 artifacts/current/screens/다.
- 기체/전장/난이도 자동 조종 시뮬레이션은 새 분기 선택을 처리하고 기존 완료·유한값·여유 난도 돌파 계약을 검사했다. 사람의 재미 평가가 아니다.
- 최대 밀도에서 일반 적 경로의 불필요한 부위 함수 호출을 줄였다. 같은 Git 기준 소스와 현재 소스를 같은 Godot 4.7.1/RTX4070Ti에서 비교한 전투+렌더+HUD+고스트의 p95 중앙값은 **9.428→9.649ms (+2.34%)**. 각 60프레임 준비·300표본·3회이며 원시 수치는 performance.json이다. 합성 적/탄/경험치·설치물 부하의 결과로 실물 저사양/휴대폰 성능 인증이 아니다.
- 최종 내보낸 Windows EXE의 창 생성·정상 OS 닫기·exit 0과 실제 플레이어 프로필 해시 불변을 확인했다. native-release.json에 대응 EXE 해시를 기록했다.
- 최종 내보낸 Web은 로컬 브라우저로 확인했다. 실제 확인한 동작과 콘솔 범위는 browser-status.json을 따른다. 네 기능의 모든 후반 조합을 브라우저에서 장시간 직접 플레이한 것은 아니다.

업적 61→62 계약과 자동 조종사의 분기 처리를 갱신했다. 사운드 검사는 현재 규칙에서 ON/OFF 동일성을 검사하며, 과거 오디오 도입 시점 대조는 명시적 옵션으로 남겼다. 처음 실패한 검사를 성공으로 표시하지 않았으며 최종 근거에는 통과한 최종 게이트와 화면 결과만 사용했다.
