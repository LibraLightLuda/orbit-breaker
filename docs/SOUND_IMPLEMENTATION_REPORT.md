## 실제 출력 캡처·신호 분석

Windows에서 렌더된 합성 조우를 실제 시간 600.002초(벽시계 601.28초) 동안 재생하고 게임 Master 출력을 48kHz/28,800,000프레임으로 녹음했다. 마이크를 쓰지 않았다. 전투·파츠·미션·보스·세 전장·낮은 체력·정지·최종 붕괴를 포함한다. 일회성 효과음 최대14개, 물리 p95 1.517ms/p99 1.861ms였다. 이것은 구성한 재현 장면이며 사람의 자연 10분 플레이 기록은 아니다.

| 캡처 | 통합 음량 | True peak | LRA |
| --- | --- | --- | --- |
| Windows 10분 Master | -26.77 LUFS-I | -7.23dBTP | 2.7 LU |
| 최종 Web 실제 출력 | -30.94 LUFS-I | -16.58dBTP | 8.4 LU |

피크 목표(-1dBTP 이하)를 통과했다. 음악 세 stem만의 초기 청취 목표(-20~-18 LUFS-I)와 위 전체 캡처 수치는 서로 다른 측정이다. 현재 믹스는 보수적인 음량이며, 사람의 청취로 음악 존재감·무기 어택·경고 피로도와 휴대폰 스피커 가독성을 확정하지 않았다. 수치 통과를 미적 품질 수용으로 간주하지 않는다.

`audio/audio-preview.ogg`는 각 60초 구간에서 9초씩 발췌한 90초 미리듣기다. `audio/audio-preview.mp4`는 동일 오디오에 정지 캡처 10장을 붙인 리뷰 영상이며 실시간 게임 영상이 아니다. 전체 출력은 `audio/long-review/mix.ogg`, 최종 Web은 `audio/browser-mix.webm`이다.

## 성능

동일 시드, 적240·탄240·보석300, 60프레임 준비 후 300샘플, OFF/ON 각3회. OFF는 음소거 상태이므로 양쪽 모두 음원을 사전 로드한다.

| 지표 | OFF | ON |
| --- | --- | --- |
| 프레임 p95 중앙값 | 10.527ms | 10.569ms |
| 전체 물리 p95 중앙값 | 4.727ms | 4.718ms |
| 별도 audio-state p95 중앙값 | 0.036ms | 0.037ms |
| ON 프레임 p99 범위 | — | 16.367~17.032ms |
| 일회성 효과음 최대 | 0 | 11 |

ON/OFF 차이는 이 환경의 측정 잡음 수준이었다. OFF 1회 p99 54.313ms 이상치도 원본에 남겼다. 이 결과는 RTX 4070 Ti에서의 합성 부하이며 저사양/모바일 60fps 보증이 아니다. static RAM 약106.5MiB는 엔진·게임 전체 값이고, 오디오 전용 PCM 증가량 32MiB 예산을 직접 계측한 값이 아니다.

## 배포·남은 한계

최신 로컬 세대는 `build/current`, 대응 증거는 `artifacts/current`, Web 복사본은 `web/`이다. Windows SHA-256 `B2D149A5EE333EFBE3316B1BD2DA79725F465E16C938A6EAD3D9CA2A7E25353E`. Web PCK `6D6CF5D543069E5243EF5569960B436046FCF95E71EE4C8028390D2E6AF0C1A5`. 기존 정상본을 보존한 뒤 검증한 후보를 교체하고 이전 배포 세대를 정리하는 guarded promotion을 사용한다. 최종 교체/정리 상태는 `artifacts/current/verification.json`, `retention-status.json`, `file-inventory.json`이 기준이다. 공개 게시/원격 push는 요청 범위가 아니므로 수행하지 않았다.

Godot 강제 `--quit-after` 렌더 종료에서는 ObjectDB4/리소스2 누수 진단이 발생한다. 실제 EXE 렌더 시작은 확인했지만 그 강제 종료를 깨끗한 종료 성공으로 세지 않았다. 정상 창 닫기 경로와 정확한 내장 pack의 정상 종료는 오류 없이 통과했다. release 템플릿은 외부 --script/scene/path override를 지원하지 않아 내장 콘텐츠 검사에는 같은 4.7.1 엔진을 사용했다. 사람의 native EXE 대화형 청취, 실물 휴대폰, Safari/iOS, 저사양·장시간 사람 플레이는 미검증이다.

기존 정책 차단 임시 디렉터리6개와 진단 로그5개, 이번 자동 승인 검토가 삭제를 차단한 `artifacts/audio-candidate`는 삭제 우회/재시도하지 않는다. 새 배포 세대 정리와 이 과거 임시 자료를 구분하며 최종 남은 경로·사유는 retention-status에 기록한다.
