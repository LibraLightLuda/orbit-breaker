## 확정 요구사항

- GitHub Pages에서 웹게임, GitHub Releases에서 Windows 실행 파일을 배포한다.
- 웹↔웹, Windows↔Windows, 웹↔Windows의 2인 협동을 지원한다.
- 랭킹은 경기 단위 익명 게시판이다. ChatGPT 로그인·계정·사용자 토큰, 랭킹용 영구 게스트 계정·복구 코드를 요구하지 않는다. 닉네임은 중복 가능한 표시 이름이며 사용자 신원이 아니다.
- 공식 순위는 서버가 실제 판정한 경기만 인정한다. 경기 ID는 중복 방지와 결과 연결에 사용한다. 클라이언트 점수만 신뢰하지 않는다.
- 개인 기록은 기존 기기에 보관하며 공개 랭킹에 계정별 병합·본인 수정 권한을 만들지 않는다.
- 한국 중심 동시 접속 50명은 목표다. 월 인프라 약 10만 원과 실제 검증된 전투 수용량을 우선하고 초과 입장은 제한한다.

## 구성

공통 Godot 클라이언트 → HTTP API/방 관리 → 경기별 Godot headless 전투 서버. Sites의 D1은 경기·시즌·랭킹 메타데이터, R2는 고스트를 저장한다. 외부 클라이언트의 익명 쓰기를 허용하되 운영자/서버 비밀은 서버에서만 사용한다. Sites가 필수 외부 API·복구를 지원하지 못하면 같은 계약을 독립 Workers/D1/R2로 옮긴다. 로컬 개발 서비스와 실제 공개 배포 증거를 구분한다.

서버는 60Hz 전투, 최대 60Hz 입력, 20Hz 상태 전달에서 시작한다. WSS 지연·손실 검사 실패 시 WebRTC 네이티브 호환성과 비용을 검증한다. 전장 공통 상태와 플레이어 상태를 분리하고 1인 난수·보상·시간·저장을 회귀 검사한다. 공유 전장은 틱당 한 번만 진행한다.

## 협동 v1

아군 피해/충돌 없음. 적 목표는 가까운 생존자이며 예고 후 고정한다. 두 생존자에 대한 안전거리로 등장한다. 등장 빈도 1.2배, 적 HP 1.6배, 기존 피해/예고/상한에서 시작한다. 파츠 압박은 참가자 평균이며 사망으로 감소하지 않는다. 팀 처치/점수는 한 번, 경험치는 회수 후 생존자 각각에게 자신의 배율로 지급한다. 아이템은 첫 접촉자, 공용 파츠는 둘, 개인 미션 파츠는 소유자에게 지급한다.

미션은 기존 개인 난수·진행·보상 상태를 재사용한다. 같은 초기 조건에서 시작하지만 아이템·보상 이후 미션 종류가 달라질 수 있다. 공통 미션 난수를 강제하면 기존 개인 보상 흐름이 달라지므로 v1은 개인 미션으로 확정한다. 처치형은 최근 5초 유효 피해 참가자에게 인정한다. 행성은 생존자 한 명 이상이 연속 12초 유지하면 성공한다. 최종 작전은 양쪽 동의, 무응답은 생존 계속이다. 기존 600초 종료와 팀 돌파를 유지한다.

강화/분기 시 함께 정지하고 동시에 선택한다. 강화 20초/분기 15초 뒤 제시된 회복, 없으면 첫 선택지를 적용한다. 수동 정지는 양쪽 동의, 회당 30초/방 누적 60초다. 체력 0에서 15초 구조 창, 동료 64px 안에서 3초 유지하면 HP 30%/전투 무적 2초로 복귀한다. 이탈·돌진·피격은 구조를 초기화한다. 각자 한 번 구조받고 이후 사망은 관전한다. 구조할 생존자가 없으면 종료한다.

로비 10분, 경기 실제 시간 30분 상한. 연결 장애 시 전체 정지, 각자 누적 30초 재접속 허용. 초과/서버 장애는 중단이며 공식 기록을 만들지 않는다. 완료 결과는 디스크 재전송 대기 자료에 먼저 보존하고 중복 없이 저장한다.

## 기록과 고스트

시즌은 한국 시간 월 단위이며 시작 시즌에 귀속한다. v1은 익명 경기 게시판이므로 과거 시즌의 서버 검증 경기도 나중에 공개할 수 있다. 종료 후24시간 확정·시즌 보상·확정 스냅샷은 아직 제공하지 않는다. 시즌×규칙×솔로/협동×난이도×전장별로 점수/생존 틱 내림차순, 동점 공동 순위다. 기체 필터와 페이지 조회를 제공한다. 전투 결과와 고스트 완료 상태를 별도로 관리한다.

기존 고스트를 계속 읽는다. 온라인 v1은 서버 전장과 양쪽 기체를 5Hz로 저장하고 기존 고스트 보간을 사용한다. 실시간 전달은 20Hz다. 20Hz 별도 궤적은 미구현이며 틱 단위 완전 재현으로 주장하지 않는다. 2초 청크, 압축 1MiB/해제 4MiB/전체 압축 64MiB 제한, 해시와 완료 매니페스트를 검증한다. 관전·탐색·시점 전환을 제공한다. 고스트 경쟁은 동일 솔로 규칙·초기 설정·시드의 비충돌 연습이며 일반 공식 순위와 싱글 성장에 넣지 않는다. 협동 고스트는 관전용이다. 다른 선택·처치로 난수 소비가 달라지면 연습 전장이 원본과 달라질 수 있다.

일반 고스트 7일, 각 보드 상위 20경기는 시즌 종료 후 90일까지 보관한다. 점수는 고스트 만료 후에도 남긴다. 서버가 로컬/Sites 만료 작업을 호출하며 기본 로컬 고스트 10GiB 상한에서는 신규 입장을 중지한다. 개인 온라인 이력은 기존 프로필의 별도 항목에 최근 20경기를 보존한다.

SQLite/Sites 메타데이터 암호화 백업·추가 복원 도구를 제공한다. 운영 목표는 일일 7개/주간 4개 독립 위치 보관, RPO 24h/RTO 4h다. 일정·독립 보관 경로와 실제 복구 시간은 공개 호스트에서 검증한다. 이 백업은 R2 고스트 바이트를 복제하지 않는다. 고스트 보존과 영구 점수 복구를 구분한다. 배포 한 세대 정리 규칙은 플레이어 데이터·복구 백업에 적용하지 않는다.

## 완료 증거

실제 웹/Windows 세 조합의 경기 완주, 익명 등록/조회, 고스트 관전/경쟁, 중복·장애·복원·입장 제한, 공개 URL/릴리즈 파일 해시 확인이 완료 조건이다. 로컬 검사와 공개 운영, 합성 입력과 실물 기기/사람 플레이를 구분한다.
