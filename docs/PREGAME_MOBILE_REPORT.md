# 모바일 시작 전 UI 검수

범위: 메인 → 출격 준비, 작전 기록, 플레이 방법, 무기/기체/아이템 도감과 상세, 설정, 라이선스. 진행 중 전투·HUD·강화·정지·결과 화면은 이번 UI 검수에서 제외한다.

## 개선

- 세로 스크롤에 넣던 시작 전 보조 화면을 내용 높이에 따른 페이지로 전환했다. 탭·돌아가기·출격·페이지 이동은 고정 영역에 둔다.
- 낮은 가로 화면은 복귀와 페이지 버튼을 같은 하단 행에 배치한다. 현재 폰트·줄바꿈·줄간격으로 높이를 계산하고, 실제 렌더에서 글자와 카드가 고정 버튼을 침범하지 않는지 검사한다.
- 작은 메인 버튼은 44px 이상 높이를 유지한다. 공간이 부족한 출격 준비는 선택 카드를 페이지에 나누고, 선택 시 위치를 유지한다.
- 화면 회전 후 현재 항목, 파일럿 이름과 기체·전장·난이도 선택을 유지한다. 터치 메뉴의 재진입 위치 애니메이션을 제거했다.
- 설정의 음량 설명과 슬라이더, 기록의 이름·통계·고스트 버튼을 같은 카드에 묶는다. 라이선스 텍스트는 모든 문자를 유지하며 페이지로 나눈다.
- 현재 동작과 달랐던 도움말의 탭 돌진 설명을 길게 끌어 놓기로 수정했다. Web의 이름 입력용 실험적 가상 키보드를 활성화했다.

## 재현

`tests/test_pregame.gd`는 320×534, 360×606, 390×810, 412×881, 568×286, 667×341, 844×356, 1024×734의 실제 렌더 창에서 시작 전 화면과 모든 페이지를 검사한다. 브라우저 상단 바를 뺀 콘텐츠 영역 크기다. 가득 찬 최근 기록 8개·랭킹 10개와 발견된 아이템의 긴 설명도 포함한다.

검사항목: 화면 경계, 텍스트·카드 경계, 고정 메뉴와 내용의 겹침, 44px 터치 높이, GUI hit test, 실제 Viewport 터치로 페이지 넘김과 화면 진입/복귀, 회전 후 상태 보존. `tools/build.ps1`에 필수 검사로 연결했다.

최종 검사 수·내보낸 파일 해시·브라우저 확인·실행 결과는 `artifacts/current/verification.json`, `results.json`, `browser-status.json`, `native-release.json`을 따른다. 과거 실행의 증거를 이번 검사의 성공으로 합산하지 않는다.

실물 휴대폰, Safari/iOS, 실제 소프트 키보드와 키보드가 열린 상태의 회전, 노치와 브라우저 주소창의 기기별 동작은 미검증이다. 공개 게시 여부는 최종 검증 명세를 따른다.
