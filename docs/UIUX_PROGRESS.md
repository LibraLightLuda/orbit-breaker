# Orbit Breaker UI/UX 실행 기록

기준: 2026-10-11 현재 작업 트리의 3.12. 기존 미커밋 변경 전체를 보존한다.
규칙·미션·파츠·기체 연구·61개 업적·저장·리플레이는 변경하지 않는다.
Nova Drift의 에너지 실루엣, Hades II의 선택 정보 위계, DRG Survivor의 출격 미리보기,
Brotato의 수치 정렬을 적용한다. Hearthstone 기반 도감의 탭·카드·페이지 구조는 유지한다.

## 공통 디자인 기준

- 깊은 남색 공간 / 청록 에너지 / 초록 준비·회복 / 금색 보상 / 붉은 위험.
- 위험은 형상·방향·문구를 함께 제공한다. 배경 장식보다 판정 예고와 플레이어를 우선한다.
- 버튼의 기본·호버·키보드 포커스·선택·잠금을 구분한다. 선택지에 추천을 암시하지 않는다.
- 기체·무기·아이템 아이콘을 선택·전투·도감에서 재사용한다. 게임 난수는 소비하지 않는다.
- 모바일은 메뉴 재배치와 스크롤·터치 영역 대비이며 터치 전투 지원은 포함하지 않는다.

## 최종 검증 보완

- 작은 창에서 강화 선택을 재배치해도 선택지·난수가 바뀌지 않는 검사와 실제 출격 클릭 검사를 추가했다.
- 폰트 MSDF·카드 줄바꿈·업적 진행 막대 높이·결과 상태 패널 범위를 실제 렌더로 수정했다.
- 게임/저장/콘텐츠 관련8개 파일은 시작 해시와 일치한다. 자동검사는16개 관문, 렌더 검사는10개 실행이다.
- 외곽 링 장식 중복을 줄여 동일 비교 기준선 p95 26.960ms → 23.789ms(-11.8%). 최대밀도60fps 수용 목표는 열려 있다.
- 최대밀도를600초 복제한 고스트 fixture는 기존32MB 한도를 넘었다. 보호 한도는 유지하고60초 고밀도 저장과 별도 실제10분 리플레이 검사를 분리했다.
- 실제 모바일 전투·저사양 실기기·Safari/Firefox·정량 Web FPS·사람의 장기 수용 평가·공개 원격 배포는 수행하지 않았다.

## 배포 결과와 남은 관문

3.13을 build/current와 artifacts/current에 승격하고 web/ 복사본·HTTP PCK 해시 일치를 확인했다. 자동 승인 검토가 재귀 삭제 및 정리 명령을 blocked by policy로 거부했다. 다른 삭제 방식으로 우회하지 않았다. 최신본 교체는 삭제 없이 진행했으며, Web 서버의 로그 파일 잠금을 해제하고 분리된 증거 파일 이동을 완료했다.

남은 구버전 경로: build/previous, build/retiring-uiux-3.12, artifacts/retiring-uiux-3.12. 한 세대 정리는 완료하지 못했다. 성능60fps·실기기/사람 수용 검증과 함께 미해결로 남긴다. artifacts/candidate는 파일이 없는 빈 준비 폴더다.
