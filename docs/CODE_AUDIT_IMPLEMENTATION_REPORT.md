## 변경 내용

1. **오디오 불변성:** 두 모델이 전술/강화 선택을 실제로 처리한 뒤 같은 입력을 받는다. 36개 조합마다 예정된 시간만큼 진행하거나 정상 종료했는지 검사해 선택 화면에서 함께 멈추는 통과를 차단한다. 실제 사망을 숨기려고 체력이나 흡수막 수치를 올리지 않는다.
2. **성능 판정:** 모델/고스트 스트레스의 p95를 엔진 물리 프레임 예산과 비교한다. 배포 검사도 기존/현재 각 3회 이상의 원시 p95 중앙값에서 10% 회귀 한계를 계산하며, 저장된 통과 플래그를 판정 근거로 쓰지 않는다. 샘플 수·적/탄환/경험치 부하와 숫자 유효성도 확인한다.
3. **소스와 출력 연결:** 최초 스냅샷과 검사 시작 시 소스 해시를 보관한다. 런타임·자산·테스트·도구와 프로젝트 설정을 내보내기 완료 때 다시 대조하고, 해당 Windows/Web 출력의 해시를 후보 검증 영수증에 연결한다. 네이티브 검사와 패키징에서 동일 영수증·소스·출력을 재확인한다. 생성 UID/바이트코드는 제외한다.
4. **실제 터치:** 제작 정보의 모든 페이지를 뷰포트 터치 입력으로 이동한다. 후기 페이지의 직접 pressed 신호 호출을 제거했다.
5. **고스트 손상 방어:** 프레임 숫자 타입을 변환 전에 검사하며, 적 종류도 현재/과거에 지원한 6종만 허용한다. 스냅샷과 생명주기 이벤트 양쪽을 검사한다.
6. **전술 선택 음악:** 전술과 그 도감을 전투 일시정지 문맥으로 유지한다. 일시정지 중인 스트림을 새로 재생하지 않고 기존 재생을 이어가며, 위치 보존을 검사한다. 테스트 종료 후 믹서가 스트림을 해제할 시간도 확보했다.
7. **리플레이 보간:** 같은 녹화·재생 시각의 전체 월드는 한 번만 계산해 물리 처리/그리기에서 공유한다. 속도 계산에는 위치 전용 이진 탐색/보간을 사용한다. 탐색과 같은 시각의 녹화 교체는 캐시를 무효화하며 기존 13/14열 고스트를 유지한다.
