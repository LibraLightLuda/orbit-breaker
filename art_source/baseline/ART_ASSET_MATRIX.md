# Orbit Breaker — 전체 그래픽 제작·사용처 목록

2026-10-12 / 3.18 소스 조사 기준 / **계획 전용**. [아트 디렉션](ART_DIRECTION_PLAN.md)의 스타일·보호 조건·검증 기준을 함께 적용한다. 아래 항목은 신규 게임 콘텐츠가 아니라 실제 코드에서 확인한 요소의 제작·교체·개선 범위다.

P0는 대표 장면을 확정하는 선행 작업, P1은 전체 완성에 필수인 확장, P2는 마지막 통합 마감이다. P2도 이번 전체 개편에서 생략하지 않는다. 상태는 전부 미착수다. 물리 이미지 장수는 아틀라스/공유 원형 결정에 따라 달라지므로 ID 개수를 파일 개수로 착각하지 않는다.

제작법: **R** = Blender 원형의 2D 렌더/아틀라스, **V** = 직접 작성 SVG·정밀 벡터 도해, **S** = Godot CanvasItem 셰이더/재질, **D** = 기존 모델 데이터로 절차적 그리기/애니메이션, **I** = 선택적인 내장 Imagegen 컨셉·배경 소스. I는 필수 의존성이 아니다. 모든 산출물은 실제 Godot 크기로 검사한다.

## 3. 12종 아이템·등급·경험치·파츠 드롭

12 ID는 `scripts/item_catalog.gd::IDS`가 기준이다. 필드 `_draw_arena`, 도감 `_show_item_codex/_show_item_detail`, `item_icon.gd`, 버프 `_draw_item_status`, 방향 `_draw_direction_marker`, 강화의 공유 상징, 관전에 동일 ID로 적용한다.

공통 외관은 떠 있는 작은 보급 컨테이너와 중앙 심벌이다. **C/B/A는 컨테이너의 1/2/3분절 테두리+기존 색+문자**로 파생하며 36종을 독립 그림으로 만들 필요는 없다. 잠김/미발견 상태는 정보 공개 규칙을 그대로 지킨다.

| ID / 이름 | 전용 심벌·획득/지속 표현 | 제작·완료 기준 |
| --- | --- | --- |
| `power` 출력 코어 | 두 장갑판 사이의 에너지 코어, 무기 코어로 흐르는 짧은 전달 | V+공유 R/D. 영구 고출력 강화와 심벌을 공유하되 일시 버프 프레임/초 단위 표시 구별 |

미션의 작은 상징은 기존 `Expedition.MISSION_IDS` 10종을 모두 연결한다. `chaser/runner/tank/shooter`는 해당 적의 새 실루엣, `survive`는 선체+시간 호, `outer`는 경계 바깥 탐사선, `outer_kills`는 경계 바깥 표적, `returns`는 경계를 왕복하는 두 화살표, `dash_hits`는 돌진 궤적+접촉점, `overdrive`는 실제 오버드라이브 코어를 사용한다. C/B/A·preview/active/success/failed는 공통 프레임으로 파생한다. 난이도 `normal/relaxed/veteran/cataclysm`도 현재 잠금·해금 상태와 점수 배율을 그대로 연결한다.

## 7. 누락 방지와 전달 계약

구현 착수 시 위 목록으로 작은 작업표를 만들고 각 항목에 `기존 경로 → 최종 원본/자산 → 소비 함수/화면 → 상태 → 증거`를 적는다. 이 표의 항목을 이미 완료된 것으로 초기화하지 않는다.

전수 확인 순서:

1. `GameContent.SHIP_IDS/SECTOR_IDS/EVOLUTION_IDS`, `ItemCatalog.IDS/GRADES`, `RunModel.UPGRADE_IDS`와`restore/burst/fortune`, `Expedition.PART_IDS/RECIPE_IDS/MISSION_IDS`, `Achievements`의 실제 ID를 열거한다. 하드코딩한 옛 목록으로 비교하지 않는다.
2. `rg`로 `draw_`, `_polygon`, `_diamond`, `_glyph`, `ItemCatalog.draw_icon`, `load/preload`, `shot.kind`, `effect.kind`, `screen`, 도감 page를 확인한다. 동적 ID 매핑·구형 고스트 분기도 검사한다.
3. 표에 등록되지 않은 glyph/fallback은 테스트에서 실패시킨다. 의도적으로 남길 도형은 체력/충전 게이지, 정확한 위험 범위, 점수 육각/경험치 마름모, 방향 화살표 등 **기능적 표식**으로 명시한다. 원·다각형을 무조건 없애는 검사는 사용하지 않는다.
4. 미발견 `?`는 정식 상태다. 이를 임시 자산으로 잘못 제거하지 않는다. 반대로 아직 제작하지 않은 신규 진화/전용 강화가 일반 다각형을 쓰는 것은 누락이다.
5. 메뉴 썸네일만 새로 바뀌고 전투가 구형이거나, 본 게임은 새롭지만 관전이 구형인 상태를 검사한다. 같은 ID에 같은 원본이 연결되는지 확인한다.
6. 원본 해상도·알파·pivot·프레임·padding·참조 경로·라이선스와 export에 최종 이미지/셰이더가 들어가는지 검사한다. 사용하지 않는 생성 후보를 무작정 게임 패키지에 포함하지 않는다.
7. 모든 중요 상태를 실제 크기의 Godot 화면과 움직임에서 확인한다. 무발광/효과 줄이기/회색조·최소 창·최대 밀도에서 실패한 항목을 다시 제작한다.

이번에 기획하지 않는 신규 자산은 캐릭터 초상화·NPC/대화 삽화·행성 지도·스토리 컷신·새 타일맵/스테이지·새 장비 종류·새 음악/음성이다. 현재 게임에 필요한 것이라는 근거가 없다. 기존 절차적 오디오의 발동·음량·mute는 시각 동기화 검사에 포함하지만 사운드 전면 개편으로 범위를 늘리지 않는다.
